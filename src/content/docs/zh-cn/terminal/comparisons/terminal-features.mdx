为了使信息更加透明和有用，我们还展示了其他 4 个流行的 macOS 终端模拟器的结果。

| 功能                                                   | Warp | Terminal.app | Iterm | Alacritty | Wezterm |
| --------------------------------------------------------- | ---- | ------------ | ----- | --------- | ------- |
| 24 位（真彩色）                                       | 是  | 否           | 是   | 是       | 是     |
| 粗体                                                      | 是  | 是          | 是   | 是       | 是     |
| 暗色                                                       | 否   | 是          | 是   | 是       | 是     |
| 斜体                                                    | 否   | 是          | 是   | 是       | 是     |
| 下划线                                                 | 是  | 是          | 是   | 是       | 是     |
| 下划线（替代）                                           | 是  | 否           | 是   | 是       | 是     |
| 双下划线                                          | 否   | 否           | 否    | 否        | 是     |
| 双下划线（替代）                                    | 是  | 否           | 是   | 是       | 是     |
| 波浪下划线                                           | 否   | 否           | 是   | 否        | 是     |
| 彩色下划线                                         | 否   | 否           | 否    | 否        | 是     |
| 闪烁                                                     | 否   | 是          | 否    | 否        | 否      |
| 反转                                                   | 是  | 是          | 是   | 是       | 是     |
| 不可见（但可复制粘贴）                           | 否   | 是          | 否    | 是       | 否      |
| 删除线                                             | 是  | 否           | 是   | 是       | 是     |
| 上划线                                                  | 否   | 否           | 否    | 否        | 是     |
| [魔法字符串](https://en.wikipedia.org/wiki/Unicode#Web) | 是  | 是          | 是   | 是       | 是     |
| Emoji                                                    | 是  | 是          | 是   | 是       | 是     |
| 从右到左                                             | 否   | 是          | 否    | 否        | 否      |
| Sixel 图形                                            | 否   | 否           | 是   | 否        | 否      |
