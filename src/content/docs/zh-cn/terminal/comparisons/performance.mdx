## 为此基准测试选择的终端应用

我们选择将 Warp 与其他 4 个终端模拟器应用进行基准测试，基于它们的流行度以及语言和设计理念。以下是我们在本次比较中选择的应用列表及其原因说明：

* Terminal.app - macOS 上可用的默认终端应用；
* ITerm2 - macOS 用户使用的最流行的终端模拟器之一；
* Alacritty 和 WezTerm - 这两个终端都是用 Rust 编写的，以速度和整体性能著称，这也是 Warp 的目标。

### 比较中使用的版本和设置

| 终端         | 版本                            | 终端尺寸（列/行，窗口像素相同） |
| ------------ | ------------------------------ | ----------------------------------------------------------- |
| Warp         | v0.2022.04.01.01.37.stable\_03 | 208 列 / 54 行                                          |
| Terminal.app | Version 2.11 (440)             | 188 列 / 72 行                                          |
| iTerm2       | Build 3.4.15                   | 211 列 / 78 行                                          |
| Alacritty    | alacritty 0.10.1 (2844606)     | 286 列 / 102 行                                         |
| Wezterm      | 20220319-142410-0fcdea07       | 243 列 / 80 行                                          |

### 关于基准测试

我们链接了每个基准测试的源代码，以便您可以轻松地使用其他终端应用重现测试。请注意，这些基准测试并非详尽无遗。将终端模拟器相互比较并非易事——目前我们正在检查每个应用在处理大量输入和/或输出时的表现。

理想情况下，基准测试还应涵盖延迟（按键和字符显示在屏幕上之间的时间，以及用户输入与 shell 通信之间的延迟）。我们将来可能会包含考虑这些因素的测试。
