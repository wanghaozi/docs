## 智能选择

**智能选择** 超越了典型的双击选择（仅高亮单个单词）。它使用语义规则将常见模式（如 URL 或文件路径）视为一个单元，即使它们被标点或空格分隔。

<figure>
![通过双击使用智能选择选择文件路径。](../../../../../assets/terminal/smart-selection.png)
<figcaption>通过双击使用智能选择选择文件路径。</figcaption>
</figure>

双击输入或块列表中的文本。识别以下模式：

1. URL
2. 文件路径
3. 电子邮件地址
4. IP 地址
5. 浮点数，包括科学计数法。

您可以在 **设置** > **功能** > **终端** > **双击智能选择** 中切换智能选择。如果禁用，您可以手动选择特定的标点字符，以包含在单词边界内。

## 矩形选择

**矩形选择** 让您以干净的垂直块（也称为 _列_ 或 _框_ 选择）高亮文本。这对于复制命令输出、日志或带前缀的文本而不抓取不需要的字符特别有用。

<figure>
![在块输出中使用矩形选择按列选择。](../../../../../assets/terminal/rectangular-selection.png)
<figcaption>在块输出中使用矩形选择按列选择。</figcaption>
</figure>

拖动鼠标时按住修饰键：

* macOS：`CMD-OPT`
* Windows 和 Linux：`CTRL-ALT`
