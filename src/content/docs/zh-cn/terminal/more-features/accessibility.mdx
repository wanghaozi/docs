我们认识到需要改善视力障碍用户的体验，因为据我们所知，其他终端模拟器应用在这方面做得不够好。本文档总结了我们目前所做的工作、Warp 如何与 VoiceOver 配合使用，并概述了与典型工作流程的主要变化。有关功能的文档及其键盘快捷键，请参阅文档中特定功能的页面。

**请记住，这是一项进行中的工作，当前状态并非 Warp 辅助功能的最终状态**。

## 如何通过 Voice Over 使用 Warp？

开始使用 Warp 和 VoiceOver 的最佳方式是使用 Homebrew 安装它：

`brew install warp`

这将确保您无需通过 macOS 标准的拖放安装过程，即可自动接收所有未来更新。

此后，Warp 应能无缝地与 VoiceOver 配合使用，并开始宣布屏幕上发生的事情以及您可以采取的操作。这可能与其他应用有重大区别——因为 Warp 自行宣布内容，让您了解正在发生的事情。目前没有办法使用 VO 键组合在不同的 UI 元素之间导航。

安装后，它会要求您登录。Warp 还会发送遥测数据，我们用来改善整体用户体验。您可以在 [隐私部分](/support-and-community/privacy-and-security/privacy/) 了解更多信息。

登录流程将要求您在应用和浏览器之间导航。在您可以开始享受我们的新终端应用之前的最后一步是填写入门调查问卷。

主终端窗口与其他终端没有太大区别——有一个输入命令的地方（命令输入）和一个之前执行的命令及其输出的列表。Warp 将它们分组在一起——每个命令和输出创建一个块。您可以使用键盘浏览块，轻松检查命令是什么，了解它是否成功，以及输出是什么，还可以更轻松地复制命令、输出或两者以供后续处理。

发现新功能和操作的主要入口是我们的命令面板，您可以通过执行 cmd-p 快捷键来访问。

## 与常规 VoiceOver 工作流程的区别

您可能会注意到，典型的 Voice Over 导航键或设置目前在 Warp 中不起作用。简而言之——这与我们的 UI 框架当前实现方式以及目前我们尚未提供键盘可访问的方式来导航 UI 元素有关。

相反，每当您执行操作和/或后台发生某些事情时，Warp 会向您宣布，让您了解正在发生的事情以及您可以采取的可能操作。由于这是一个终端，我们从一开始就关注所有用户操作都应通过键盘访问，因此几乎所有功能都已分配了按键绑定。您可以按照此 GitHub 仓库的指南调整默认键位绑定：[https://github.com/warpdotdev/keysets](https://github.com/warpdotdev/keysets)。您也始终可以使用 cmd-p 来检查键位绑定或执行特定操作。

### 辅助功能特定操作

一些辅助功能特定的设置可以通过命令面板访问。例如，您可以调整消息的详细程度。只需进入 [命令面板](/terminal/command-palette/) 并输入"a11y"以发现相关选项及其键位绑定。

### 语音输入

Warp 支持语音输入作为与终端交互的替代方式。这对于偏好或需要语音命令而非打字的用户特别有帮助。您可以使用语音输入来：

* 发出终端命令
* 询问命令使用相关问题
* 执行复杂的多步操作

语音输入可以在 **设置** > **代理** > **Warp 代理** > **语音** 中启用。有关语音功能和设置的详细信息，请参阅我们的 [语音文档](/agent-platform/local-agents/interacting-with-agents/voice/)。

## 未来工作

虽然并非所有 Warp 功能都已无障碍化，但我们已经围绕发布新功能和对主应用的更改实施了流程，以确保所有新代码提供适当的辅助功能公告。

这不是理想的和最终的实现。我们很高兴听到您关于如何改进的想法和意见。这项工作的最大里程碑是增加对使用键盘导航 UI 元素的支持。试试 Warp，请毫不犹豫地 [分享您的反馈](/support-and-community/troubleshooting-and-support/sending-us-feedback/)。
