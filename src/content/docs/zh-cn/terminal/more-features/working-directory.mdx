## 什么是工作目录

Warp 的工作目录功能旨在通过允许您为新会话设置默认目录来增强您的工作流程。此功能帮助您节省时间，在启动新会话时快速访问您的首选目录。您可以灵活地为所有新会话设置工作目录，或根据特定需求为窗口、标签和窗格单独自定义。

## 如何访问

* 打开 **设置** > **功能** > **会话**，然后转到"新会话的工作目录"。
* 此功能的下拉菜单提供了以下几个选项：
  * 主目录，是新会话的默认选项，在当前登录用户的主文件夹 `~/` 中打开新会话。
  * 上一个会话的目录，在您活动会话的当前目录中打开新会话。
  * 自定义目录，在您指定的文件路径中打开新会话。
  * 高级，允许您为窗口、标签和窗格中的新会话从三个选项中选择。
