## 什么是启动配置

通过启动配置，您可以在应用中保存配置或通过添加 yaml 文件来保存。

## 创建启动配置

### 从 UI

1. 设置您想要保存的窗口、标签和窗格的配置。
2. 打开 [命令面板](/terminal/command-palette/)，输入 `保存新启动配置`。
3. 命名配置文件。名称字段不能为空。
4. 点击保存配置按钮。

### 使用 YAML 文件

* 启动配置文件是在您使用 UI 创建时生成的，也可以手动创建或修改。
* 请参见下方的 [启动配置 YAML 文件位置、格式和示例](/terminal/sessions/launch-configurations/#launch-configuration-yaml-format)。

## 使用启动配置

<Tabs>
  <TabItem label="macOS">
    * 从 [命令面板](/terminal/command-palette/)，输入 `启动配置` 打开并选择启动配置。
    * 右键单击新标签的 **+** 按钮以打开菜单并选择已保存的启动配置。
    * 从 macOS 菜单栏，**文件** > **启动配置**，您可以搜索并打开已保存的启动配置。
      * 在 macOS 上，可以使用 `CMD-ENTER` 从启动配置面板将单窗口启动配置启动到活动窗口中。
  </TabItem>
  <TabItem label="Windows">
    * 从 [命令面板](/terminal/command-palette/)，输入 `启动配置` 打开并选择启动配置。
    * 右键单击新标签的 **+** 按钮以打开菜单并选择已保存的启动配置。
      * 在 Linux 上，可以使用 `CTRL-ENTER` 从启动配置面板将单窗口启动配置启动到活动窗口中。

    要使用启动配置打开 WSL 标签，您必须先将 WSL 设置为 Warp 中的默认 shell：

    * 前往 **设置** > **功能** > **会话** > **新会话的启动 shell**。
    * 选择您想要的 WSL 发行版（例如 Ubuntu）作为默认 shell。

    此后，您打开的任何启动配置都将使用 WSL 作为 shell。
  </TabItem>
  <TabItem label="Linux">
    * 从 [命令面板](/terminal/command-palette/)，输入 `启动配置` 打开并选择启动配置。
    * 右键单击新标签的 **+** 按钮以打开菜单并选择已保存的启动配置。
      * 在 Linux 上，可以使用 `CTRL-ENTER` 从启动配置面板将单窗口启动配置启动到活动窗口中。
  </TabItem>
</Tabs>

## 启动配置 YAML 格式

所有启动配置 yaml 文件都存储在以下位置：

<Tabs>
  <TabItem label="macOS">
    ```bash
    $HOME/.warp/launch_configurations/
    ```
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    $env:APPDATA\warp\Warp\data\launch_configurations\
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/launch_configurations/
    ```
  </TabItem>
</Tabs>

:::caution
yaml 代码中的 `cwd:` 值必须包含绝对路径或 `""`。请注意，`~` 或空路径将导致文件在启动配置选项列表中不可见。
:::

### 窗口

展示窗口在启动配置文件中如何结构的示例配置。

```yaml
# Warp 启动配置
#
# 此配置有两个窗口，
# 每个窗口在不同起始目录中有一个标签。

---
name: 示例窗口
windows:
  - tabs:
      - title: 文档
        layout:
          cwd: /Users/warp-user/Documents
        color: blue
  - tabs:
      - title: Warp 用户
        layout:
          cwd: /Users/warp-user
        color: green
```

### 标签

展示标签在启动配置文件中如何结构的示例配置。

* 使用 `title` 字段设置自定义标签名称
* 使用 `color` 字段设置标签颜色
  *   我们目前支持使用终端颜色（ANSI 颜色）：

      `红色 | 绿色 | 黄色 | 蓝色 | 洋红色 | 青色`

      实际颜色值将自动从您的 Warp 主题派生

```yaml
# Warp 启动配置
#
# 此配置在同一个窗口中有两个标签。

---
name: 示例标签
windows:
  - tabs:
      - title: 文档 
        layout:
          cwd: /Users/warp-user/Documents
        color: blue
      - title: Warp 用户
        layout:
          cwd: /Users/warp-user
        color: green
```

### 窗格

启动配置支持在每个标签中设置拆分窗格。请注意，Warp 也支持在启动配置文件中嵌套拆分窗格。

```yaml
# Warp 启动配置
#
# 此配置有两个窗口，每个窗口带有拆分窗格。 
# 第一个窗口包含一个垂直拆分的标签，有两个窗格。
# 第二个窗口包含一个水平拆分的标签，
# 右侧有一个垂直拆分的标签。

---
name: 示例窗格
windows:
  - tabs:
      - title: 下载和 Warp 用户
        layout:
          split_direction: vertical
          panes:
            - cwd: /Users/warp-user/Downloads
            - cwd: /Users/warp-user
        color: blue
  - tabs:
      - title: 桌面、文档和 Warp 用户
        layout:
          split_direction: horizontal
          panes:
            - cwd: /Users/warp-user/Desktop
            - split_direction: vertical
              panes:
                - cwd: /Users/warp-user/Documents
                - cwd: /Users/warp-user
        color: green
```

### 活动和焦点

展示如何激活窗口和标签并使会话获得焦点的示例配置。

* 使用 `active_window_index` 和 `active_tab_index` 字段设置您的活动窗口和标签。
* 使用 `is_focused` 字段设置每个标签中哪个窗格获得焦点。

:::caution
请注意，当您使用 `- active_tab_index:` 时，`tabs:` 字段不需要 `-` 前缀，因为这可能导致语法问题。
:::

```yaml
# Warp 启动配置
#
# 此配置有两个标签，第二个标签为活动标签。
# 第一个标签中有两个垂直拆分窗格，顶部窗格获得焦点。
# 第二个标签中有两个水平拆分窗格，右侧窗格获得焦点。
---
name: 示例活动和焦点
active_window_index: 0
windows:
  - active_tab_index: 1
    tabs:
      - title: 标签 1
        layout:
          split_direction: vertical
          panes:
            - cwd: /Users/warp-user/Documents
              is_focused: true
            - cwd: /Users/warp-user/Documents/Projects
      - title: 标签 2
        layout:
          split_direction: horizontal
          panes:
            - cwd: /Users/warp-user/Downloads
            - cwd: /Users/warp-user
              is_focused: true
```

### 命令

使用 `commands` 字段定义启动配置运行时执行的一组命令。

:::caution
对于包含特殊字符的命令，您可能需要使用双引号。不同行的命令在运行时使用 `&&` 连接起来，因此 `ssh` 命令之后运行的命令可能不会执行。
:::

```yaml
# Warp 启动配置
#
# 此配置有两个窗口，
# 第一个窗口在启动时执行两个命令，
# 第二个窗口有一个在启动时执行命令的拆分窗格。

---
name: 示例命令
windows:
  - tabs:
      - title: 文档
        layout:
          cwd: /Users/warp-user/Documents
          commands:
            - exec: ls
            - exec: code .
        color: blue
  - tabs:
      - title: 下载
        layout:
          split_direction: vertical
          panes:
            - cwd: /Users/warp-user/Downloads
              commands:
                - exec: curl http://example.com -o my.file
                - exec: cp my.file my.file2
            - cwd: /Users/warp-user
              commands:
                - exec: ssh user@remote.server.com
        color: green
```
