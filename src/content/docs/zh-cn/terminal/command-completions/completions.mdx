## 什么是补全

补全功能具有模糊搜索能力，为您的查询提供[近似匹配](https://en.wikipedia.org/wiki/Approximate_string_matching)建议。如果您不确定确切的语法或拼写，系统会根据您的输入提供建议，即使不是精确匹配。

## 如何访问

* 输入命令的开头，然后按 `TAB`。
* 要搜索选项和标志，您必须输入并按 `TAB`。
* 无需 `TAB`：在 **设置** > **功能** > **终端输入** 中启用"输入时打开补全菜单"

## 如何使用

### 补全

1. 输入 `git checkout`（注意空格），然后按 `TAB`
2. 菜单将显示所有本地分支。您可以使用鼠标或 `UP ↑`/`DOWN ↓` 箭头键选择一个

### 别名补全

* Shell 别名 - 这是整个命令的别名。例如，如果您有别名 `gc=git checkout`，输入 `gc` 并按 `TAB` 应显示与 `git checkout` 相同的补全选项。
* 命令别名 - 这是子命令的别名。例如，可以将 `git status` 设置为 `git st`。有了补全支持，我们现在可以建议 `git status` 的补全，即使您输入的是 `git st`。

:::note
**终端技巧**\
**设置** > **功能** > **终端输入** 中的"Tab 键行为"设置可以更改 `Tab` 绑定的操作。如果 `Tab` 未绑定到打开补全菜单，则 `ctrl-space` 将被分配为默认快捷键。_注意：您也可以在 **设置** > **功能** > **终端输入** 中启用"输入时打开补全菜单"，以便补全菜单自动打开。_
:::
