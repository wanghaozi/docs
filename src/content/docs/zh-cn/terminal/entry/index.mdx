1. [命令纠正](/terminal/entry/command-corrections/) 为之前运行过的命令提供自动更正建议，以捕获拼写错误、遗漏的标志，并修复一般的控制台错误。
2. [命令搜索](/terminal/entry/command-search/) 是一个三合一面板，允许您同时搜索命令历史、工作流、笔记本和 AI 命令搜索。
3. [命令历史](/terminal/entry/command-history/) 允许 Warp 隔离每个 shell 会话的历史，使之前运行过的命令易于访问。
4. [同步输入](/terminal/entry/synchronized-inputs/) 允许您轻松地在多个会话中同时运行相同的命令。
5. [YAML 工作流](/terminal/entry/yaml-workflows/) 是在 Warp 中更轻松地执行和共享参数化、可搜索命令的方式。
