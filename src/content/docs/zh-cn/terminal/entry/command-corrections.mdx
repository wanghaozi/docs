## 什么是命令纠正

此功能建立在开源项目 [nvdn/thefuck](https://github.com/nvbn/thefuck) 之上。以下是 Warp 团队通常发现命令纠正有用的一些示例：

* 拼写错误的命令
  * `gti checkout myBranchName` -> `git checkout myBranchName`
  * `cd ap/sorce/executtor` -> `cd app/source/executor`
* 遗漏的标志
  * `git push` -> `git push –set-upstream myBranchName`
* 添加权限
  * `./script` -> `chmod +x ./script && ./script`

## 如何访问

* 命令纠正默认启用。您可以通过前往 **设置** > **功能** > **终端输入** > 切换"建议纠正的命令"来禁用命令纠正。
* 运行错误命令后，输入编辑器上方会出现一个带有纠正命令建议的面板。`点击`或按 `RIGHT` 箭头以插入建议。
