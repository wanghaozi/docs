1. [标签](/terminal/windows/tabs/) 允许您将窗口组织成多个终端会话。
2. [垂直标签](/terminal/windows/vertical-tabs/) 用侧边栏替换水平标签栏，显示丰富的元数据，并支持每个标签和窗格的拖放管理。
3. [拆分窗格](/terminal/windows/split-panes/) 允许您将标签分成多个矩形 _窗格_，每个窗格都是一个唯一的终端会话。
4. [标签配置](/terminal/windows/tab-configs/) 允许您在简单的 TOML 文件中定义可重用的标签设置。
5. [全局热键](/terminal/windows/global-hotkey/) 是一个可配置的快捷键，可以显示/隐藏一个专用窗口或所有窗口在您选择的桌面上，无论应用是否获得焦点。
6. [启动配置（旧版）](/terminal/sessions/launch-configurations/) 支持保存窗口、标签和窗格的配置以供以后打开。
