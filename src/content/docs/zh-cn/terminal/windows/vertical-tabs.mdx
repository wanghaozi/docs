垂直标签面板是一个侧边栏，用更丰富、更强大的标签管理界面取代传统的水平标签栏。面板不是单行标签标题，而是为每个标签和窗格显示带有上下文元数据——Git 分支、工作目录、代理对话状态、差异统计等——的信息。无需切换上下文即可扫描和切换工作流。

垂直标签在并排运行多个编码代理时特别有用，让您无需切换标签即可清晰了解每个会话的状态。

## 主要功能

### 丰富的元数据和状态

* **窗格元数据** - 一目了然地查看每个窗格的工作目录、Git 分支、代理对话状态、差异统计和 PR 徽章。
* **代理状态徽章** - 窗格图标显示彩色徽章叠加，指示代理状态（进行中、完成、错误、已取消或阻塞）。[第三方 CLI 代理](/agent-platform/cli-agents/overview/)（如 Claude Code、Codex 和 Gemini CLI）显示其品牌图标和颜色，旁边是徽章。
* **通知指示器** - 在有未读代理活动的窗格行上出现强调色圆点，因此您无需切换标签即可发现需要注意的会话。

### 显示模式和自定义

* **窗格或标签视图** - 将每个拆分窗格显示为单独的行（**窗格**），或仅显示每个标签的聚焦窗格（**标签**）。
* **聚焦会话或摘要标签项** - 在查看 **标签** 时，选择 **聚焦会话** 以显示每个标签的活动窗格，或 **摘要** 以显示标签中每个窗格的紧凑多行摘要（命令、工作目录、分支和状态徽章）。
* **紧凑和展开模式** - 选择密集的单行视图（默认）或带有完整元数据的详细多行布局。
* **可配置的窗格标题** - 控制哪个元数据首先显示：最后命令或对话、工作目录或 Git 分支。
* **悬停详细信息侧边窗口** - 将鼠标悬停在任何窗格行上，可以在浮动详情卡片中查看完整的、未裁剪的元数据，而无需更改焦点。

### 标签管理

* **搜索、拖放和重命名** - 按标题、目录或分支过滤窗格；通过拖动重新排序标签或在标签之间移动窗格；双击标签内联重命名。
* **新标签菜单** - 从统一的 **+** 菜单创建代理标签、终端标签、云代理会话、工作树配置和 [标签配置](/terminal/windows/tab-configs/)。

## 启用垂直标签

要从水平标签切换到垂直标签面板：

1. 在 Warp 应用中，导航至 **设置** > **外观** > **标签**。
2. 打开 **使用垂直标签布局**。

垂直标签面板作为可调整大小的侧边栏出现在窗口的左侧。垂直标签激活时，水平标签栏被隐藏。

## 视图模式

垂直标签面板支持两种显示密度，您可以随时切换。

### 紧凑模式

紧凑模式是默认模式。每个窗格行在一行上显示图标和标题，下方有可选的副标题。副标题可通过设置弹出窗口中的 **附加元数据** 设置进行配置。

<figure style={{ maxWidth: "375px" }}>
![垂直标签侧边栏紧凑模式，每个窗格行显示图标、标题和下方简短副标题](../../../../../assets/terminal/vertical-tabs-condensed.png)
<figcaption>垂直标签紧凑模式。</figcaption>
</figure>

### 展开模式

展开模式显示每个窗格行的标题、描述（如工作目录或文件路径）和元数据（Git 分支、差异统计徽章和 PR 徽章，如果可用）。

<figure style={{ maxWidth: "375px" }}>
![垂直标签行展开模式，显示标题、工作目录、Git 分支、差异统计和代理状态徽章](../../../../../assets/terminal/vertical-tabs-multi-agent.png)
<figcaption>垂直标签概览。</figcaption>
</figure>

### 切换视图模式

点击垂直标签面板顶部控制栏中的设置图标（滑块）。在弹出窗口中，使用 **密度** 分段控制在紧凑和展开视图之间切换。更改立即生效。

## 自定义垂直标签

当垂直标签启用时，从设置弹出窗口（点击控制栏中的滑块图标）或从 **设置** > **外观** > **标签** 配置它们的外观和行为。

您还可以重新排列 Warp 窗口顶部的面板切换按钮——包括标签面板、工具面板、代理管理、代码审查和通知信箱——并在头部左右两侧之间移动它们。详情请参见 [可配置工具栏](/terminal/windows/configurable-toolbar/)。

| 设置 | 可用性 | 选项 | 默认值 |
|---|---|---|---|
| **视图方式** | 始终 | **窗格** — 每个拆分窗格获得自己的行。**标签** — 每个标签一行，进一步由 **标签项** 设置控制。 | 窗格 |
| **标签项** | **视图方式** 设置为 **标签** | **聚焦会话** — 显示聚焦窗格的标题和元数据。**摘要** — 显示标签中每个窗格的紧凑摘要，包含命令或对话标题、工作目录、分支和代理状态徽章（最多三行，带有 `+ N 更多` 溢出行）。 | 聚焦会话 |
| **密度** | 始终 | **紧凑** — 较小的行，带有标题和可选副标题。**展开** — 较大的行，带有标题、描述和元数据。 | 紧凑 |
| **窗格标题** | 始终 | **命令/对话** — 最后命令、对话标题或 CLI 代理会话名称。<br />**工作目录** — 窗格的工作目录。<br />**分支** — 检出的 Git 分支。 | 命令/对话 |
| **附加元数据** | 紧凑模式仅 | **分支**<br />**工作目录**<br />**命令/对话**<br />（选项取决于 **窗格标题** 设置；重复项被排除）。 | 分支 |
| **显示** | 展开模式仅 | **PR 链接** — 当前分支的拉取请求和状态（需要 GitHub CLI）。**差异统计** — 添加/删除的行数。 | — |
| **悬停显示详细信息** | 始终 | 开/关 — 切换悬停详细信息侧边窗口。 | 开 |

### 自动元数据

以下元数据自动显示，无需配置：

* **Git 分支** - 窗格工作目录当前检出的分支。
* **工作树** - 当前的 [Git 工作树](/code/git-worktrees/) 路径（如果适用）。
* **代理状态** - 窗格图标上的彩色徽章，指示代理的当前状态（参见下面的 [代理状态徽章](#agent-status-badges)）。
* **通知圆点** - 当窗格有未读代理活动时，标题行上的强调色圆点。

## 代理状态徽章

代理窗格图标在右下角显示一个小的圆形徽章叠加，反映代理的当前状态：

| 状态 | 图标 | 含义 |
|---|---|---|
| **进行中** | 洋红色时钟 | 代理正在积极运行。 |
| **完成** | 绿色勾号 | 代理的上一次轮次成功完成。 |
| **错误** | 红色三角形 | 代理的上一次轮次以错误完成。 |
| **已取消** | 灰色停止 | 用户取消了代理的上一次轮次。 |
| **阻塞** | 黄色停止 | 代理正在等待用户批准以继续。 |

第三方 CLI 代理（Claude Code、Codex、Gemini CLI 等）在圆形窗格图标内显示其品牌图标和颜色，并带有相同的状态徽章叠加。

当窗格有未读代理活动时，标题行的右边缘会出现一个强调色通知圆点。当您聚焦窗格时，圆点会清除。

## 管理标签

### 搜索

垂直标签面板顶部的控制栏包括一个搜索字段。键入以按标题、工作目录、Git 分支、PR 标签或差异统计过滤可见的标签和窗格。搜索查询活动时，只有匹配的标签保持可见。

### 新标签菜单

点击控制栏中的 **+** 按钮打开新标签菜单。菜单包括：

* **代理** - 打开一个新的代理标签。
* **终端** - 打开一个新的终端标签。
* **云代理** - 打开一个新的云代理会话标签。
* **标签配置** - 您已创建的 [标签配置](/terminal/windows/tab-configs/) 会作为菜单项出现，可一键设置。
* **新建工作树配置** - 创建新的基于工作树的标签配置。
* **新建标签配置** - 从起始模板创建新的标签配置。

### 拖放

通过在面板内拖动标签组标题来重新排序标签。要将窗格从一个标签移动到另一个标签，将窗格标题拖动到面板中的另一个标签组上。Warp 会切换到该标签，以便您可以使用标准放置目标放置窗格。将窗格放置在标签组之间会在该位置创建一个新标签。

### 标签重命名

双击标签行以内联重命名。按 `Enter` 确认或按 `Esc` 取消。

:::note
重命名仅适用于标签。单个窗格目前无法重命名。
:::

## 悬停详细信息侧边窗口

悬停任何窗格行会打开一个浮动详情卡片，锚定在面板的右侧。侧边窗口显示完整的、未裁剪的元数据（完整的目录路径、完整的分支名称以及完整的对话或命令标题），而无需更改聚焦的窗格。

<figure style={{ maxWidth: "375px" }}>
![垂直标签面板，Claude Code 标签悬停，显示浮动详情卡片，包含代理的进行中状态、工作目录和会话标题](../../../../../assets/terminal/tab-hover-detail-card.png)
<figcaption>垂直标签的悬停详情卡片。</figcaption>

当您将光标从行移动到卡片时，侧边窗口保持打开。离开行和侧边窗口以关闭它。在设置弹出窗口中切换 **悬停显示详细信息** 以禁用此行为。

## 键盘快捷键

所有现有的标签键盘快捷键在垂直标签中继续有效。侧边栏布局更改的是标签的显示方式，而不是您与它们交互的方式。有关标签快捷键的完整列表，请参见 [终端标签](/terminal/windows/tabs/)。
