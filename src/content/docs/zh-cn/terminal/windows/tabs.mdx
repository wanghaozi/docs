## 如何使用标签

<Tabs>

    * 使用 `CMD-T` 或点击顶部栏中的 `+` 打开新标签。

:::tip
**终端技巧**\
在 macOS 或 Linux 上使用您的 `.zshrc` 或 `.bashrc` 文件，您可以设置新的标签名称：

```bash
# 设置名称，其中 MyTabName 可以是您想在标签中看到的任何内容（固定字符串、$PWD 或其他）
function set_name () {
  export WARP_DISABLE_AUTO_TITLE=true
  echo -ne "\033]0;MyTabName\007"
}
# 在 Zsh 或 Bash 中将函数添加到环境变量
if [ -n "$ZSH_VERSION" ]; then
  preexec_functions+=(set_name)
elif [ -n "$BASH_VERSION" ]; then
  PROMPT_COMMAND='set_name'
fi
```
了解更多关于标签名称的信息 [此处](https://learn.microsoft.com/en-us/windows/terminal/tutorials/tab-title#set-the-shells-title)。
:::

### 标签恢复

标签恢复使您可以在最多 60 秒内重新打开最近关闭的标签。在 **设置** > **功能** > **会话** > **启用重新打开已关闭的会话** 中配置此功能。

### CTRL-TAB 行为

`CTRL-TAB` 快捷键默认激活上一个/下一个标签。您可以在 **设置** > **功能** > **键** > **Ctrl-Tab 行为** 中配置快捷键以循环最近会话，包括任何 [拆分窗格](/terminal/windows/split-panes/)。

### 标签行为

请参见我们的 [外观 > 标签行为](/terminal/appearance/tabs-behavior/) 文档以获取更多标签相关设置。
