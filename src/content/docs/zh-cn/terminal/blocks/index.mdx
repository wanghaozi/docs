块是 Warp 组织终端输出的基本单元。每个命令及其输出被分组到单个块中，您可以独立复制、搜索、过滤、书签、分享和导航——用结构化的、可操作的内容取代传统终端的无尽滚动。

## 什么是块？

块让我们可以轻松地：

* 复制命令
* 复制命令的输出
* 直接滚动到命令输出的起始位置
* 重新输入命令
* 分享命令及其输出（带格式！）
* 为命令添加书签
