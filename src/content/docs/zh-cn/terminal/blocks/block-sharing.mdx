通过永久链接或 HTML 嵌入分享您的块。您可以通过打开上下文菜单并复制命令、输出或提示符来开始使用共享块。

## 如何分享块

<Tabs>
  <TabItem label="macOS">
    要分享您的块，请按照以下步骤操作：

    1. 在已完成的块上，点击上下文菜单并选择 **分享...** 或选中块并按 `CMD-SHIFT-S`。
    2. 将弹出一个模态框，让您为块命名，并通过选择要分享的块的部分（例如命令、输出、提示符等）来定制它。
    3. 根据您想要分享块的方式，点击"创建链接"或"获取嵌入代码"。
    4. 链接或嵌入代码片段将被复制到您的剪贴板。
  </TabItem>
  <TabItem label="Windows">
    要分享您的块，请按照以下步骤操作：

    1. 在已完成的块上，点击上下文菜单并选择 **分享...**，或在 **设置** > **键盘快捷键** 中为分享块设置快捷键。
    2. 将弹出一个模态框，让您为块命名，并通过选择要分享的块的部分（例如命令、输出、提示符等）来定制它。
    3. 根据您想要分享块的方式，点击"创建链接"或"获取嵌入代码"。
    4. 链接或嵌入代码片段将被复制到您的剪贴板。
  </TabItem>
  <TabItem label="Linux">
    要分享您的块，请按照以下步骤操作：

    1. 在已完成的块上，点击上下文菜单并选择 **分享...**，或在 **设置** > **键盘快捷键** 中为分享块设置快捷键。
    2. 将弹出一个模态框，让您为块命名，并通过选择要分享的块的部分（例如命令、输出、提示符等）来定制它。
    3. 根据您想要分享块的方式，点击"创建链接"或"获取嵌入代码"。
    4. 链接或嵌入代码片段将被复制到您的剪贴板。
  </TabItem>
</Tabs>

## 嵌入块

创建并将您的块嵌入到网页中，帮助读者跟随技术文档。读者可以像在 Warp 中一样与嵌入的块交互，包括上下文菜单和样式。当您点击"获取嵌入代码"时，Warp 会将一个 `iframe` 复制到您的剪贴板。以下是一个 `iframe` 示例：

```html
<iframe src="https://app.warp.dev/block/embed/qn0g1CqQnkYjEafPH5HCVT"
title="服务器脚本错误" style="width: 712px; height: 397px; border:0;
overflow:hidden;" allow="clipboard-read; clipboard-write"></iframe>
```

## 管理共享块

您可以通过导航至 **设置** > **共享块** 来取消分享一个块。目前，任何拥有链接的人都可以访问共享块。

## 链接预览

共享的永久链接还将为每个链接显示代码预览，以便快速了解上下文。

:::note
兼容任何支持 Open Graph 或 Twitter 元标签的平台。例如 Slack、Twitter、Facebook、Telegram、Notion 等 ...
:::
