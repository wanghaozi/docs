## 什么是后台块

命令可以启动后台进程，这些进程甚至在命令退出后仍继续运行。您也可以直接从 shell 启动后台进程，例如使用 `&` 运行它。

如果 Warp 收到的输出可能来自后台进程，则该输出将进入一个 _后台块_。后台块的行为类似于常规块，只是它们没有关联的命令。

这让您可以将 Warp 的所有块功能（如分享和书签）用于后台输出。

## 如何使用

后台块会根据需要在常规块运行之间自动创建。如果您在后台进程仍在产生输出时运行命令，则该输出将被拆分为多个与您的命令交错排列的块。

## 后台块故障排除

存在一些限制，因为 Warp 不知道任何给定输出来自 _哪个_ 进程：

* 如果后台进程在常规块中运行前台命令时写入输出，则该输出会进入该块。
* 如果同时运行多个后台进程，它们的输出可能会混合在一起。

此外，如果您在另一个命令正在运行时开始输入命令（提前输入/typeahead），在某些情况下，Warp 会将部分命令误认为是后台输出。最常见的原因是在使用 bash 4.0 之前的版本时编辑提前输入（例如，删除并重新输入部分内容）。
