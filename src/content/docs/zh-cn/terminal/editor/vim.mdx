## 关于 Vim 键绑定

Vi 系列程序（包括 Vim 和 Neovim）是模态文本编辑器，允许键盘驱动的文本编辑。几个 shell，包括 `bash` 和 `zsh`，实现了 vi 风格的键绑定。Warp 的输入编辑器原生构建以支持更现代的文本编辑体验，这意味着它替代了 shell 的编辑器能力。Warp 有自己的 Vim 键绑定实现（也称为 Vim 模式）供您使用。

### 如何启用 Vim 键绑定

:::note
对于 `bash` 和 `zsh`，Warp 会尝试检测 shell 的键绑定设置。如果检测到 shell vi 模式，Warp 可能会建议启用 Vim 键绑定（也称为 Vim 模式）。
:::

要手动切换 Warp 输入编辑器中的 Vim 键绑定：

* 通过 [命令面板](/terminal/command-palette/)，搜索"Vim 键绑定"。
* 通过 **设置** > **功能** > **文本编辑**，切换"使用 Vim 键绑定编辑命令"。

与 `bash` 和 `zsh` 的 vi 模式实现一样，编辑器以插入模式启动。按 `CTRL-C` 或 `ENTER` 会清除任何待处理的命令状态。

### 自定义键绑定

目前，Warp 只支持默认的 Vim 键绑定。

一个例外是退出插入模式的键盘快捷键，可以在 **设置** > **键盘快捷键** > **退出 Vim 插入模式** 中重新绑定，或者通过 [命令面板](/terminal/command-palette/) 搜索"退出 Vim 插入模式"。

## 支持的键绑定

以下是在 Warp 中已实现的 vim 功能列表。

### 移动

参见 [Vim 文档：移动](https://vimdoc.sourceforge.net/htmldoc/motion.html) 了解更多信息。

#### 基本

| 命令                           | 描述                                         |
| ---------------------------- | --------------------------------------------------- |
| `h`, `j`, `k`, `l`           | 单字符移动                                |
| `<space>`, `<backspace>`     | 带行换行的单字符移动                 |
| `w`, `W`, `b`, `B`, `e`, `E` | 单词移动                                       |
| `ge`, `gE`                   | 上一个单词的结尾                                |
| `$`                          | 行尾                                         |
| `0`                          | 行首                                   |
| `^`                          | 行的第一个非空白字符              |
| `%`                          | 跳转到匹配的括号                            |
| `[`, `]`                     | 上一个/下一个不匹配的括号                         |
| `_`                          | 当前行的开头                       |
| `+`                          | 下一行的第一个非空白字符     |
| `-`                          | 上一行的第一个非空白字符 |

#### 多行相关

| 命令 | 描述             |
| ---------- | ----------------------- |
| `gg`, `G`  | 跳转到第一行/最后一行 |

### 编辑

| 命令 | 描述                                                 |
| ---------- | ----------------------------------------------------------- |
| `r`        | 替换光标下的字符                              |
| `d`, `D`   | 删除范围或对象                                    |
| `c`, `C`   | 修改范围或对象（删除，然后进入插入模式）   |
| `s`, `S`   | 替换（类似修改，但只能在光标处删除） |
| `x`, `X`   | 删除光标下的内容                                         |
| `y`, `Y`   | 复制（拉取）到剪贴板                              |
| `p`, `P`   | 从剪贴板粘贴                                    |
| `u`, `⌃r`  | 撤销、重做                                                  |
| `~`        | 切换光标下字符的大小写                         |
| `gu`       | 将光标下字符变为小写（视觉模式下为 `u`）                 |
| `gU`       | 将光标下字符变为大写（视觉模式下为 `U`）                 |
| `J`        | 合并当前行和下一行                            |
| `.`        | 重复上次编辑                                            |

参见 [Vim 文档：编辑](https://vimdoc.sourceforge.net/htmldoc/editing.html) 了解更多信息。

#### 文本对象

| 命令             | 描述                                |
| ---------------- | ------------------------------------------ |
| `i`              | 内部（排除文本对象中的分隔符）  |
| `a`              | 周围（包括文本对象中的分隔符） |
| `w`, `W`         | 空白分隔的字符串（单词）         |
| `"`, `'`, \`\`\` | 引号分隔的字符串                     |
| `(`, `{`, `[`    | 括号/花括号分隔的字符串             |

参见 [Vim 文档：文本对象](https://vimdoc.sourceforge.net/htmldoc/motion.html#text-objects) 了解更多信息。

### 搜索

#### 字符搜索

| 命令             | 描述                                            |
| ------------------ | ------------------------------------------------------ |
| `t`, `T`, `f`, `F` | 在行上查找下一个/上一个匹配字符              |
| `;`                | 以相同方向重复上次字符搜索     |
| `,`                | 以相反方向重复上次字符搜索 |

参见 [Vim 文档：左右移动](https://vimdoc.sourceforge.net/htmldoc/motion.html#f) 了解更多信息。

#### 通用搜索

与 Vim 不同，通用搜索命令不会在缓冲区中搜索。相反，它们会打开 Warp 的原生命令搜索。

| 命令             | 描述              |
| ------------------ | ------------------------ |
| `/`, `?`, `*`, `#` | 打开 Warp 命令搜索 |

### 模式切换

| 命令 | 描述                                                       |
| ---------- | ----------------------------------------------------------------- |
| `i`        | 在光标前插入文本                                     |
| `I`        | 在行中第一个非空白字符前插入文本 |
| `a`        | 在光标后追加文本                                      |
| `A`        | 在行尾追加文本                                |
| `o`        | 在光标下方开始新行并插入文本                   |
| `O`        | 在光标上方开始新行并插入文本                   |
| `v`        | 视觉字符模式                                             |
| `V`        | 视觉行模式                                                  |

参见 [Vim 文档：插入](https://vimdoc.sourceforge.net/htmldoc/insert.html#insert) 和 [Vim 文档：视觉模式](https://vimdoc.sourceforge.net/htmldoc/visual.html#visual-mode) 了解更多信息。

### 寄存器

| 命令 | 描述     |
| ---------- | --------------- |
| `"`        | 寄存器前缀 |

Warp 目前支持以下寄存器：

| 寄存器名称    | 描述                                                      |
| ---------------- | ---------------------------------------------------------------- |
| `a`–`z`, `A`–`Z` | 命名寄存器                                                  |
| `+`              | 系统剪贴板                                                 |
| `*`              | 系统剪贴板                                                 |
| `"`              | 未命名寄存器，包含上次删除或拉取的文本 |

参见 [Vim 文档：寄存器](https://vimdoc.sourceforge.net/htmldoc/change.html#registers) 了解更多信息。
