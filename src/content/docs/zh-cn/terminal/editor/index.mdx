Warp 的输入编辑器的工作方式类似于现代 IDE 文本编辑器，内置光标移动、点击定位、多行编辑、复制粘贴、单词选择和软换行。与传统终端不同，您可以像编辑代码一样编辑命令——无需记住特定于 shell 的快捷方式。

:::note
文本编辑器输入同样适用于 [SSH 会话](/terminal/warpify/ssh/)。
:::

### 软换行

Warp 支持输入编辑器中的软换行。如果自动建议超出屏幕范围，输入编辑器将变为水平可滚动以使其可见。某些操作将软换行的行视为逻辑行（`三击`），而其他操作将软换行的行视为可见的不同行（`UP`/`DOWN`、`SHIFT-UP`/`SHIFT-DOWN`）。

### 选择时复制

Warp 支持对 [块](/terminal/blocks/) 内的可选文本进行选择时复制。

* 在 **设置** > **功能** > **终端** 中切换此功能，或在 [命令面板](/terminal/command-palette/) 中搜索"选择时复制"。

### 自动补全引号、圆括号和方括号

Warp 可以像您在 IDE 中习惯的那样自动补全引号、括号和方括号。

* 在 **设置** > **功能** > **文本编辑** 中切换此功能，或在 [命令面板](/terminal/command-palette/) 中搜索"自动补全引号"。
