---
title: Warpify 概览
description: >-
  Warp 支持在本地或远程会话中启用 Warp 功能的 Warpify 特性。
---

1. [子 shell](/terminal/warpify/subshells/)，Warp 支持在 bash、zsh 和 fish 的子 shell 中启用 Warp 功能。
2. [SSH](/terminal/warpify/ssh/)，Warp 的 SSH 扩展将文件树、可靠的补全和原生代码差异带到远程 macOS 和 Linux 主机。基于旧版 tmux 的 Warpification 仍然适用于尚未提供扩展的客户端。
3. [SSH 旧版](/terminal/warpify/ssh-legacy/)，Warp 支持一个旧版包装器，可在远程（SSH）会话中启用 Warp 功能。
