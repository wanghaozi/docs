此页面列出了您可以在 [`settings.toml`](/terminal/settings/) 中配置的每个设置，按 TOML 部分组织。有关设置文件的介绍、如何打开它以及常见配置示例，请参见 [设置文件](/terminal/settings/)。

设置被分组到对应于 TOML 表标题的部分中（例如 `[appearance.text]`）。只包含您想要更改的设置——Warp 对其他所有内容使用内置默认值。

## 通用

控制 Warp 启动行为、会话管理和窗口级偏好的顶级设置。

**部分**：`[general]`

* `default_session_mode` — 新终端会话的默认模式。类型：string。默认值：`"terminal"`。选项：`"terminal"`、`"agent"`、`"cloud_agent"`、`"tab_config"`、`"docker_sandbox"`。
* `default_tab_config_path` — 当 `default_session_mode` 为 `"tab_config"` 时使用的标签配置路径。类型：string。默认值：`""`。
* `link_tooltip` — 悬停在链接上时是否显示工具提示。类型：boolean。默认值：`true`。
* `login_item` — 是否在登录时自动启动 Warp。类型：boolean。默认值：`true`。
* `mouse_scroll_multiplier` — 鼠标滚轮事件的滚轮速度倍率。类型：number。默认值：`3.0`。
* `new_tab_placement` — 新标签在标签栏中的放置位置。类型：string。默认值：`"after_current_tab"`。选项：`"after_current_tab"`、`"after_all_tabs"`。
* `quit_on_last_window_closed` — 关闭最后一个窗口时是否退出 Warp。类型：boolean。默认值：`false`。
* `restore_session` — 启动 Warp 时是否恢复上一个会话。类型：boolean。默认值：`true`。
* `should_confirm_close_session` — 关闭会话时是否显示确认对话框。类型：boolean。默认值：`true`。
* `show_changelog_after_update` — 更新后是否显示变更日志。类型：boolean。默认值：`true`。
* `show_warning_before_quitting` — 退出 Warp 前是否显示警告对话框。类型：boolean。默认值：`true`。
* `snackbar_enabled` — 是否显示 snackbar 通知。类型：boolean。默认值：`true`。
* `user_native_preference` — 是否偏好原生桌面应用还是 Web 应用。类型：string。默认值：`"not_selected"`。选项：`"not_selected"`、`"web"`、`"desktop"`。

### 撤销关闭

**部分**：`[general.undo_close]`

* `enabled` — 是否启用撤销关闭功能。类型：boolean。默认值：`true`。
* `grace_period` — 关闭标签后可撤销关闭的时间（秒）。类型：integer。默认值：`60`。

## 外观

控制 Warp 外观的视觉设置，包括主题、字体、光标、标签、窗口和布局。

**部分**：`[appearance]`

* `spacing` — 控制终端块之间的间距。类型：string。默认值：`"normal"`。选项：`"normal"`、`"compact"`。

### 主题

**部分**：`[appearance.themes]`

* `theme` — 颜色主题。类型：string。默认值：`"dark"`。选项：`"adeberry"`、`"phenomenon"`、`"dark"`、`"dracula"`、`"fancy_dracula"`、`"cyber_wave"`、`"solar_flare"`、`"solarized_dark"`、`"willow_dream"`、`"light"`、`"dark_city"`、`"gruvbox_dark"`、`"red_rock"`、`"jelly_fish"`、`"leafy"`、`"koi"`、`"solarized_light"`、`"snowy"`、`"gruvbox_light"`、`"pink_city"`、`"marble"`，或一个自定义主题对象。
* `system_theme` — 是否匹配系统的浅色/深色主题。类型：boolean。默认值：`false`。
* `selected_system_themes` — 系统浅色和深色模式使用的主题。类型：object。默认值：`{ dark = "dark", light = "light" }`。

要使用自定义主题：

```toml
[appearance.themes]
theme = { custom = { name = "My Theme", path = "~/.warp/themes/my-theme.yaml" } }
```

### 文本

**部分**：`[appearance.text]`

* `font_name` — 终端中使用的等宽字体。类型：string。默认值：`"Hack"`。
* `font_size` — 终端中等宽字体的大小。类型：number。默认值：`13.0`。
* `font_weight` — 等宽字体的粗细。类型：string。默认值：`"normal"`。选项：`"thin"`、`"extra_light"`、`"light"`、`"normal"`、`"medium"`、`"semibold"`、`"bold"`、`"extra_bold"`、`"black"`。
* `line_height_ratio` — 终端文本的行高比例。类型：number。默认值：`1.2`。
* `ligature_rendering_enabled` — 是否在终端中渲染字体连字。类型：boolean。默认值：`false`。
* `ai_font_name` — AI 生成内容使用的字体。类型：string。默认值：`"Hack"`。
* `match_ai_font` — AI 字体是否自动匹配终端字体。类型：boolean。默认值：`false`。
* `notebook_font_size` — 笔记本中使用的字体大小。类型：number。默认值：`14.0`。
* `match_notebook_to_monospace_font_size` — 笔记本字体大小是否匹配终端字体大小。类型：boolean。默认值：`true`。
* `use_thin_strokes` — 是否在 macOS 上使用细字体描边。类型：string。默认值：`"on_high_dpi_displays"`。选项：`"never"`、`"on_low_dpi_displays"`、`"on_high_dpi_displays"`、`"always"`。
* `enforce_minimum_contrast` — 是否强制文本使用最小对比度以提高可读性。类型：string。默认值：`"only_named_colors"`。选项：`"never"`、`"only_named_colors"`、`"always"`。

### 光标

**部分**：`[appearance.cursor]`

* `cursor_display_type` — 光标的视觉样式。类型：string。默认值：`"bar"`。选项：`"bar"`、`"block"`、`"underline"`。
* `cursor_blink` — 光标是否闪烁。类型：string。默认值：`"enabled"`。选项：`"enabled"`、`"disabled"`。

### 块

**部分**：`[appearance.blocks]`

* `show_block_dividers` — 是否显示终端块之间的分隔线。类型：boolean。默认值：`true`。
* `show_jump_to_bottom_of_block_button` — 是否在长命令输出中显示跳转到底部按钮。类型：boolean。默认值：`true`。
* `should_show_bootstrap_block` — 引导块是否在终端中可见。类型：boolean。默认值：`false`。
* `should_show_in_band_command_blocks` — 带内命令块是否可见。类型：boolean。默认值：`false`。
* `should_show_ssh_block` — SSH 连接块是否可见。类型：boolean。默认值：`false`。

### 标签

**部分**：`[appearance.tabs]`

* `workspace_decoration_visibility` — 工作区装饰（如标签栏）何时可见。类型：string。默认值：`"hide_fullscreen"`。选项：`"always_show"`、`"hide_fullscreen"`、`"on_hover"`。
* `tab_close_button_position` — 标签上关闭按钮的位置。类型：string。默认值：`"right"`。选项：`"right"`、`"left"`。
* `show_indicators_button` — 是否在标签上显示活动指示器。类型：boolean。默认值：`true`。
* `preserve_active_tab_color` — 切换标签时是否保留活动标签的颜色。类型：boolean。默认值：`false`。
* `header_toolbar_chip_selection` — 垂直标签面板标题中头部工具栏芯片的配置。类型：string 或 object。默认值：`"default"`。

### 垂直标签

**部分**：`[appearance.vertical_tabs]`

* `enabled` — 是否垂直显示标签而不是水平显示。类型：boolean。默认值：`false`。
* `view_mode` — 垂直标签栏的显示模式。类型：string。默认值：`"compact"`。选项：`"compact"`、`"expanded"`。
* `primary_info` — 垂直标签上显示的主要信息。类型：string。默认值：`"command"`。选项：`"command"`、`"working_directory"`、`"branch"`。
* `compact_subtitle` — 紧凑垂直标签上显示的副标题。类型：string。默认值：`"branch"`。选项：`"branch"`、`"working_directory"`、`"command"`。
* `display_granularity` — 垂直标签面板中显示的行粒度。类型：string。默认值：`"panes"`。选项：`"panes"`、`"tabs"`。
* `tab_item_mode` — 垂直标签中的标签项显示模式。类型：string。默认值：`"focused_session"`。选项：`"focused_session"`、`"summary"`。
* `show_details_on_hover` — 悬停在垂直标签上时是否显示详细信息侧边窗口。类型：boolean。默认值：`true`。
* `show_diff_stats` — 是否在垂直标签上显示差异统计。类型：boolean。默认值：`true`。
* `show_pr_link` — 是否在垂直标签上显示 PR 链接。类型：boolean。默认值：`true`。
* `use_latest_prompt_as_title` — 代理对话的垂直标签名称是否使用最新的用户提示。类型：boolean。默认值：`false`。

### 窗格

**部分**：`[appearance.panes]`

* `focus_pane_on_hover` — 窗格悬停时是否聚焦。类型：boolean。默认值：`false`。
* `should_dim_inactive_panes` — 非活动窗格是否视觉上变暗。类型：boolean。默认值：`false`。

### 输入位置

**部分**：`[appearance.input]`

* `input_mode` — 终端输入的位置。类型：string。默认值：`"pinned_to_bottom"`。选项：`"pinned_to_bottom"`、`"pinned_to_top"`、`"waterfall"`。

### 全屏应用

**部分**：`[appearance.full_screen_apps]`

* `alt_screen_padding` — 控制全屏终端应用周围的内边距。类型：string 或 object。默认值：`{ custom = { uniform_padding = 0.0 } }`。

### 图标

**部分**：`[appearance.icon]`

* `app_icon` — Dock 中显示的应用图标。类型：string。默认值：`"default"`。选项：`"default"`、`"aurora"`、`"classic1"`、`"classic2"`、`"classic3"`、`"comets"`、`"cow"`、`"glass_sky"`、`"glitch"`、`"glow"`、`"holographic"`、`"mono"`、`"neon"`、`"original"`、`"starburst"`、`"sticker"`、`"warp_one"`。

### 窗口

**部分**：`[appearance.window]`

* `override_opacity` — 窗口背景的不透明度，从 1 到 100 百分比。类型：integer。默认值：`100`。
* `override_blur` — 应用于窗口背景的模糊半径。类型：integer。默认值：`1`。
* `override_blur_texture` — 是否对窗口背景应用模糊纹理。类型：boolean。默认值：`false`。
* `zoom_level` — 窗口的缩放级别，以百分比表示。类型：integer。默认值：`100`。
* `open_windows_at_custom_size` — 是否以自定义大小而不是默认大小打开新窗口。类型：boolean。默认值：`false`。
* `new_windows_num_columns` — 使用自定义大小时新窗口的列数。类型：integer。默认值：`80`。
* `new_windows_num_rows` — 使用自定义大小时新窗口的行数。类型：integer。默认值：`40`。
* `left_panel_visibility_across_tabs` — 左侧面板的可见性是否在所有标签之间共享。类型：boolean。默认值：`true`。

## 终端

控制终端行为、输入和事件处理的设置。

**部分**：`[terminal]`

* `copy_on_select` — 选择文本时是否自动复制到剪贴板。类型：boolean。默认值：`true`。
* `focus_reporting_enabled` — 是否将焦点和失焦事件转发给全屏终端应用。类型：boolean。默认值：`true`。
* `mouse_reporting_enabled` — 是否将鼠标事件转发给全屏终端应用。类型：boolean。默认值：`true`。
* `scroll_reporting_enabled` — 是否将滚轮事件转发给全屏终端应用。类型：boolean。默认值：`true`。
* `maximum_grid_size` — 终端网格的最大行数。类型：integer。默认值：`50000`。
* `use_audible_bell` — 是否在终端响铃事件时播放可听铃声。类型：boolean。默认值：`false`。
* `show_terminal_zero_state_block` — 是否在新终端会话中显示 AI 零状态块。类型：boolean。默认值：`true`。

### 输入

**部分**：`[terminal.input]`

* `syntax_highlighting` — 终端输入中是否启用语法高亮。类型：boolean。默认值：`true`。
* `honor_ps1` — 是否使用 shell 的 PS1 提示符而不是 Warp 提示符。类型：boolean。默认值：`false`。
* `input_box_type_setting` — 终端输入样式。类型：string。默认值：`"classic"`。选项：`"universal"`（AI 优先输入）、`"classic"`（终端优先输入）。
* `alias_expansion_enabled` — 输入中是否启用 shell 别名展开。类型：boolean。默认值：`false`。
* `command_corrections` — 是否为拼写错误的命令建议命令纠正。类型：boolean。默认值：`true`。
* `error_underlining_enabled` — 输入中是否给命令错误添加下划线。类型：boolean。默认值：`true`。
* `completions_open_while_typing` — 输入时补全菜单是否自动打开。类型：boolean。默认值：`false`。
* `classic_completions_mode` — 是否启用经典补全模式。类型：boolean。默认值：`false`。
* `show_hint_text` — 终端输入中是否显示提示文本。类型：boolean。默认值：`true`。
* `show_terminal_input_message_bar` — 是否显示终端输入消息栏。类型：boolean。默认值：`true`。
* `enable_slash_commands_in_terminal` — 终端输入中是否可使用斜杠命令。类型：boolean。默认值：`true`。
* `at_context_menu_in_terminal_mode` — 终端模式下 @ 上下文菜单是否可用。类型：boolean。默认值：`true`。
* `outline_codebase_symbols_for_at_context_menu` — @ 上下文菜单中是否显示代码库符号。类型：boolean。默认值：`true`。
* `middle_click_paste_enabled` — 中键点击是否从剪贴板粘贴。类型：boolean。默认值：`true`。
* `extra_meta_keys` — 控制哪些额外按键被视为元键。类型：object。默认值：`{ left_alt = false, right_alt = false }`。

* `keybinding_hint` — 是否显示自动建议的键位绑定提示。类型：boolean。默认值：`true`。

## 会话

控制新会话的 shell 选择和工作目录行为的设置。

**部分**：`[session]`

* `startup_shell_override` — Warp 启动时使用的 shell。类型：string 或 null。默认值：`null`（使用系统默认）。
* `new_session_shell_override` — 打开新会话时使用的 shell。类型：string、object 或 null。默认值：`null`（使用系统默认）。选项：`"system_default"`、`{ executable = "/path/to/shell" }`、`{ custom = "command" }`。

### 工作目录配置

**部分**：`[session.working_directory_config]`

* `advanced_mode` — 是否对每个会话源使用单独的设置。类型：boolean。默认值：`false`。

当 `advanced_mode` 为 `false` 时，`[session.working_directory_config.global]` 表适用于所有会话源。当为 `true` 时，您可以独立配置每个源。

**部分**：`[session.working_directory_config.global]`（以及 `.split_pane`、`.new_tab`、`.new_window`）

* `mode` — 如何确定工作目录。类型：string。默认值：`"previous_dir"`。选项：`"home_dir"`、`"previous_dir"`、`"custom_dir"`。
* `custom_dir` — 自定义目录路径，当模式为 `"custom_dir"` 时使用。类型：string。默认值：`""`。

```toml
# 为拆分窗格使用特定目录，为其他所有内容使用上一个目录
[session.working_directory_config]
advanced_mode = true

[session.working_directory_config.global]
mode = "previous_dir"
custom_dir = ""

[session.working_directory_config.split_pane]
mode = "custom_dir"
custom_dir = "~/projects"

[session.working_directory_config.new_tab]
mode = "previous_dir"
custom_dir = ""

[session.working_directory_config.new_window]
mode = "home_dir"
custom_dir = ""
```

## 代理

Warp 代理的设置，包括模型行为、权限、知识、MCP 服务器和语音输入。

**部分**：`[agents]`

* `cloud_conversation_storage_enabled` — 对话是否存储在云端。类型：boolean。默认值：`true`。

### 知识

**部分**：`[agents.knowledge]`

* `rules_enabled` — 代理在请求期间是否使用您保存的规则。类型：boolean。默认值：`true`。
* `warp_drive_context_enabled` — AI 请求中是否包含 Warp Drive 上下文。类型：boolean。默认值：`true`。

### MCP 服务器

**部分**：`[agents.mcp_servers]`

* `file_based_mcp_enabled` — 是否自动生成来自第三方代理的全局基于文件的 MCP 服务器。Warp 管理的全局 MCP 服务器无论此设置如何都会自动生成，项目范围的服务器必须手动启动。类型：boolean。默认值：`false`。

### 配置文件（权限）

**部分**：`[agents.profiles]`

* `agent_mode_coding_permissions` — 代理的文件读取权限级别。类型：string。默认值：`"always_ask_before_reading"`。选项：`"always_ask_before_reading"`、`"always_allow_reading"`、`"allow_reading_specific_files"`。
* `agent_mode_coding_file_read_allowlist` — 代理无需询问即可读取的文件路径。类型：字符串数组。默认值：`[]`。
* `agent_mode_execute_readonly_commands` — 代理是否可以自动执行只读命令而无需询问。类型：boolean。默认值：`false`。
* `agent_mode_command_execution_allowlist` — 代理无需显式权限即可执行的命令（正则表达式模式）。类型：字符串数组。默认值：`["cat(\\s.*)?", "echo(\\s.*)?", "find .*", "grep(\\s.*)?", "ls(\\s.*)?", "which .*"]`。
* `agent_mode_command_execution_denylist` — 代理在执行前必须始终询问的命令（正则表达式模式）。类型：字符串数组。默认值：`["bash(\\s.*)?", "fish(\\s.*)?", "pwsh(\\s.*)?", "sh(\\s.*)?", "zsh(\\s.*)?", "curl(\\s.*)?", "eval(\\s.*)?", "exec(\\s.*)?", "source(\\s.*)?", "wget(\\s.*)?", "dig(\\s.*)?", "nslookup(\\s.*)?", "host(\\s.*)?", "ssh(\\s.*)?", "scp(\\s.*)?", "rsync(\\s.*)?", "telnet(\\s.*)?", "rm(\\s.*)?"]`。

### Warp 代理（AI 功能）

**部分**：`[agents.warp_agent]`

* `is_any_ai_enabled` — 控制是否启用所有 AI 功能。类型：boolean。默认值：`true`。

#### Active AI

**部分**：`[agents.warp_agent.active_ai]`

* `enabled` — 控制是否启用主动式 AI 功能（如建议）。类型：boolean。默认值：`true`。
* `code_suggestions_enabled` — 控制是否启用 AI 代码建议。类型：boolean。默认值：`true`。
* `intelligent_autosuggestions_enabled` — 控制是否启用 AI 驱动的智能自动建议。类型：boolean。默认值：`true`。
* `agent_mode_query_suggestions_enabled` — 控制代理模式中是否显示提示建议。类型：boolean。默认值：`true`。
* `shared_block_title_generation_enabled` — 控制分享块时是否自动生成标题。类型：boolean。默认值：`true`。

#### 输入

**部分**：`[agents.warp_agent.input]`
