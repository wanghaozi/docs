description: >-
  智能体可以直接在 Warp 中生成和编辑代码。

当你首次进入一个 Git 仓库时，Warp 将进入初始化流程，为你的代码库建立索引并生成一个 AGENTS.md 文件。

当你处于仓库中时，Warp 将进入高级代码生成流程，当检测到有编写代码的机会时，支持单行和多文件更改。

例如，当你提示时，Warp 可能会编写代码：

* **代码创建**："编写一个 JavaScript 函数来实现防抖输入"
* **基于错误输出，建议修复**："修复这个 TypeScript 错误。"
* **编辑单个文件**："将此文件中的所有'var'实例更新为'let'。"
* **批量更改**："为此目录中的所有 .py 文件添加标头"

**体验此功能的最佳方式是亲自尝试——** [_在 Warp 中打开以下提示_](https://app.warp.dev/drive/prompt/Generate-a-custom-Warp-theme-K8oloLrCZAHuaYKfz2cNqI)

```text
根据当前操作系统检测正确的 Warp 主题目录：
- 在 macOS 上，使用 ~/.warp/themes/
- 在 Linux 上，使用 ${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes/
- 在 Windows 上，使用 $env:APPDATA\warp\Warp\data\themes\

如果目录不存在，请创建它。

然后，生成一个名为 {{theme_name}} 的自定义 Warp 主题，格式为有效的 YAML，遵循 Warp 文档中的官方结构。排除 background_image 字段，不要包含任何额外或缺失的字段。将主题保存为 {{theme_name}}.yaml 到检测到的主题目录中。

创建并验证主题后，通过告诉我主题文件的保存位置来确认完成。
```

### 上下文

#### 代码库上下文

Warp 可以索引你的 Git 跟踪代码库，以帮助智能体理解你的代码并生成准确、上下文感知的响应。**Warp 服务器上不会存储任何代码**。

你可以在**设置** > **代码** > **索引和项目**中的"已初始化/已索引文件夹"下查看和管理已索引的代码库。你还可以指定是否在浏览新文件夹时自动索引它们。

如果你的代码库很大，可以将特定文件添加到 `.warpindexingignore` 文件中以排除它们。

#### 其他类型的上下文

你可以直接向智能体提供不同类型的输入作为上下文，以引导其行为并提高响应质量。这包括：

* 终端输出中的[块](/agent-platform/local-agents/agent-context/blocks-as-context/)
* [图片](/agent-platform/local-agents/agent-context/images-as-context/)
* [文件和代码](/agent-platform/local-agents/agent-context/using-to-add-context/)（使用 @ 符号）
* 通过 URL 提供的[公共网站](/agent-platform/local-agents/agent-context/urls-as-context/)

#### Warp Drive 作为上下文

智能体会直接从你的 [**Warp Drive**](/knowledge-and-collaboration/warp-drive/) 内容中获取信息，以生成更准确的响应——包括你的**工作流**、**笔记本**、**提示**和**环境变量**。

* 使用时，上下文会出现在对话中的"引用"或"源自"部分。
* 此设置**默认启用**，可通过以下方式管理：**设置** > **智能体** > **知识** > **Warp Drive 作为智能体模式上下文**。

#### 规则

**规则**让你为智能体提供持久上下文，从而实现更智能、更个性化的响应。

你可以创建全局规则（通过 [Warp Drive](/knowledge-and-collaboration/warp-drive/) > **个人** > **规则**访问）或项目范围规则，在 `AGENTS.md` 文件中定义。注意：文件名必须全部大写，Warp 才能识别。

**规则示例包括：**

* 编码标准和最佳实践
* 项目或工作空间特定的指南
* 对工具、格式或行为的个人偏好

如何访问项目特定的规则

1. 从文件搜索器中，按 `CMD+O` 并搜索 "AGENTS.md"
2. 从文件树中，在仓库中时点击"代码"图标

如何访问全局规则

1. 从 [Warp Drive](/knowledge-and-collaboration/warp-drive/) > **个人** > **规则**
2. 从[命令面板](/terminal/command-palette/)中，搜索"打开 AI 规则"
3. 从设置面板，**设置** > **智能体** > **知识** > **管理规则**
4. 从 macOS 菜单，`AI > 打开规则`
