Warp 启动时会显示一个快捷键界面，展示一些最常用的键盘快捷键。点击 x 按钮可隐藏快捷键界面。通过[命令面板](/terminal/command-palette/)或资源中心的键盘快捷键侧边栏可以快速查看键盘快捷键。

## 自定义键盘快捷键

导航至**设置** > **键盘快捷键**，可以设置自定义快捷键、清除快捷键或恢复为默认快捷键。使用搜索栏搜索可重新映射的操作或现有的快捷键。

使用文件重新映射键盘快捷键。请参阅我们的 [keysets 仓库](https://github.com/warpdotdev/keysets/tree/main)获取说明。

:::note
在 macOS 上，需要先[解除绑定](https://support.apple.com/guide/mac-help/keyboard-shortcuts-mchlp2262/mac)[系统键盘快捷键](https://support.apple.com/en-us/HT201236)（如 `CMD-ESC`、`CMD-BACKTICK`、`CMD-TAB`、`CMD-PERIOD` 和 `CMD-TILDE`），才能在 Warp 中使用它们。
:::

:::caution
与其他键位冲突的快捷键会以橙色边框高亮显示。
:::
