Warp 的用户来自各种终端、编辑器和 AI 编码工具。本部分为每个最常见的来源提供了专门的页面，包含逐步迁移指南、自动转移内容的说明，以及 Warp 功能与你当前工具的对照参考。

选择你要转换的工具：

* [**Claude Code**](/getting-started/migrate-to-warp/migrate-to-warp-from-claude-code/) - 在 Warp 中使用 Claude Code，或从 Claude Code 切换到 Warp 内置的智能体模式。涵盖上下文、规则和模型设置。
* [**Cursor**](/getting-started/migrate-to-warp/migrate-to-warp-from-cursor/) - 将 Warp 作为智能体终端与 Cursor 一起使用，或完全用 Warp 内置的代码编辑器和智能体模式取代 Cursor。
* [**Ghostty**](/getting-started/migrate-to-warp/migrate-to-warp-from-ghostty/) - 将你的 Ghostty 配置迁移到 Warp，并寻找快速终端、标签页和 GPU 渲染的对应功能。
* [**iTerm2**](/getting-started/migrate-to-warp/migrate-to-warp-from-iterm2/) - 使用 Warp 内置的 iTerm2 导入工具，只需点击几下即可转移主题、字体、键位和热键窗口。
* [**macOS 终端**](/getting-started/migrate-to-warp/migrate-to-warp-from-macos-terminal/) - 匹配你的 Terminal.app 设置，发现终端应用缺少的分屏、标签页和智能体模式功能。
* [**VS Code 终端**](/getting-started/migrate-to-warp/migrate-to-warp-from-vs-code-terminal/) - 将 Warp 与 VS Code 一起使用以获得更强大的终端，或完全用 Warp 内置的代码编辑器取代 VS Code。
* [**Windows 终端**](/getting-started/migrate-to-warp/migrate-to-warp-from-windows-terminal/) - 在 Windows 上将 Windows 终端的配置文件、PowerShell 设置和配色方案映射到 Warp。

## 从其他工具迁移？

Warp 同样适合从许多其他来源迁移的开发人员。如果你正在从上面未列出的工具（例如 Alacritty、WezTerm、Kitty、Hyper，或 Linux 默认的 GNOME 终端、Konsole）切换，请在我们的 [Discord 社区](https://discord.gg/warpdotdev)中留言，以便我们优先处理覆盖范围。
