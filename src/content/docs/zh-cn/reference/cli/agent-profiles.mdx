代理配置文件控制从 Oz CLI 运行时代理可以做什么、如何运作以及可以在何处行动。在 Warp 应用中创建配置文件，以配置文件访问、命令执行、MCP 服务器使用、模型选择和目录权限，然后在 CLI 命令中通过 ID 引用它们。

代理配置文件控制三个方面：

* **代理可以做什么** — 文件访问、命令执行和 MCP 服务器使用
* **代理的工作方式** — 模型选择、自主级别和响应风格
* **代理可以在何处行动** — 目录允许列表和拒绝列表

您可以在 Warp 应用中创建和配置代理配置文件。有关详细说明，请参见[代理配置文件和权限](/agent-platform/capabilities/agent-profiles-permissions/)。

代理配置文件会自动同步到您安装 Warp 的每个主机，因此您也可以在远程使用它们。

:::note
**提示：** 对于 CLI 使用，创建一个专用配置文件。如果代理尝试执行被禁止的操作，CLI 将失败，因此请确保您的配置文件允许您计划使用的目录、命令和 MCP 服务器。
:::

:::caution
CLI 使用的默认配置文件具有广泛的权限，赋予代理读取和写入文件、应用代码差异以及执行命令的能力（带有默认拒绝列表）。默认情况下，代理不能使用 MCP 服务器。
:::

## 在 CLI 中使用配置文件

1. 使用 `oz agent profile list` 查找配置文件 ID：

```sh
$ oz agent profile list
+--------------+------------------------+
| 名称         | ID                     |
+=======================================+
| Default      | AnTb02PZfrkVC9l4V15eH1 |
|--------------+------------------------|
| Coding       | CWhozDJPdPCsjJ1pSG0HCN |
|--------------+------------------------|
| Command Line | hV6n5dNm7ThQVlOiPF8DLS |
+--------------+------------------------+
```

2. 使用 `--profile` 标志传递该 ID：

```sh
$ oz agent run --profile CWhozDJPdPCsjJ1pSG0HCN --prompt "更新我的 CI 流水线以使用 nextest"
```

:::note
`--profile` 标志仅在 `oz agent run` 上可用。云端运行（`oz agent run-cloud`）不使用代理配置文件。
:::
