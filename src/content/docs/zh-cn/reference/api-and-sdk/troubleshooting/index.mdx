当 Oz 平台 API 遇到错误时，它会返回一个结构化的响应，遵循 [RFC 7807（HTTP API 的问题详情）](https://datatracker.ietf.org/doc/html/rfc7807)，包含机器可读的错误码、HTTP 状态和可操作的处理步骤。
