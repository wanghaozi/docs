Warp 是一个[开源](https://github.com/warpdotdev/warp)**智能开发环境**，它将现代高性能终端与强大的 Agent 相结合，帮助您构建、测试、部署和调试代码。Warp 的 Agent 由 **Oz** 驱动，Oz 是一个用于在本地或云端大规模运行 Agent 的编排平台。

## Warp

Warp 是您工作的地方——一个为 Agent 编码而构建的快速、现代终端。

**关键能力：**

* [**终端和 Agent 模式**](/agent-platform/local-agents/interacting-with-agents/terminal-and-agent-modes/)：在用于命令的简洁终端和用于多轮 Agent 工作流的专用对话视图之间自由切换。
* [**现代终端 UX**](/terminal/editor/)：光标移动、基于区块的导航、多行编辑、语法高亮和丰富的补全功能。使用 Rust 构建，性能卓越。
* [**代码编辑器**](/code/overview/)：文件树、支持 LSP 的代码编辑器以及交互式代码审查体验。
* [**第三方 CLI Agent**](/agent-platform/cli-agents/overview/)：在 Warp 的 Agent 工具栏中运行 Claude Code、Codex 和 OpenCode 等第三方 CLI Agent——支持丰富输入、代码审查、通知等功能。

## Oz：云端 Agent 的编排平台

Oz 是为云端 Agent 打造的编排平台，驱动着 Warp 的所有智能功能。Oz 旨在大规模协调 Agent——理解您的代码库、自主执行任务、并适应您的工作流。Oz 设计为多模型架构，让您灵活地为每个任务选择最佳的 LLM。

Oz 以两种模式运行：

### 本地 Agent

直接在 Warp 应用中运行，提供实时、交互式的编码辅助。

* 在您的代码库中编写和重构代码
* 调试问题并修复错误
* 运行命令并解释结果
* 规划并执行多步骤任务

本地 Agent 让您始终掌控全局。您可以审查更改、在任务执行中引导 Agent，并在操作执行前进行审批。

→ [开始使用本地 Agent](/agent-platform/local-agents/overview/)

### 云端 Agent

云端 Agent 在 Warp 的基础设施（或您自己的基础设施）上后台运行，实现规模化自动化。

* **触发器**：响应来自 Slack、Linear、GitHub 或自定义 Webhook 的事件
* **定时任务**：运行重复性任务，如依赖更新或死代码清理
* **并行执行**：跨仓库或任务同时运行多个 Agent
* **可观测性**：每次运行都可追踪、可审计，并与您的团队共享

云端 Agent 非常适合不需要您立即关注的工作，如 PR 审查、问题分类、日常维护和集成驱动的工作流。

→ [了解云端 Agent](/agent-platform/cloud-agents/overview/)

## 如何协同工作

Warp 和 Oz 在本地和云端开发中提供统一的体验：

* **同一 Agent，随处可用**：无论您是在 Warp 中交互式工作，还是在云端运行 Agent，使用的都是相同的底层 Agent 能力。
* **无缝交接**：在云端启动任务，当需要亲手控制时在 Warp 中接管，不会丢失进度或上下文。
* **共享上下文**：[Warp Drive](/knowledge-and-collaboration/warp-drive/)、[规则](/agent-platform/capabilities/rules/)和 [MCP 服务器](/agent-platform/capabilities/mcp/)在本地和云端 Agent 之间通用，您的团队知识和工具始终可用。
* **团队协作**：共享 Agent 会话、审查 Agent 的操作、以及引导运行中的任务，无论由谁启动。

## 开源

Warp 客户端在 [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) 下开源。源代码位于 [`warpdotdev/warp`](https://github.com/warpdotdev/warp)，您可以在此阅读代码、提交 Issue，并与 Warp 团队一起贡献代码。开发过程以 Agent 优先的工作流在公开环境中进行，由 Oz 管理。

→ [贡献给 Warp](/support-and-community/community/contributing/) 说明了如何提交 Issue、认领任务以及提交代码或主题。

## 隐私与安全

Warp 符合 **SOC 2 标准**，并与所有签约的 LLM 提供商执行**零数据保留**政策。没有任何客户 AI 数据被保留、存储或用于训练。

Warp 的 AI 功能可在**设置** > **Agent** > **Warp Agent** 中全局禁用。

→ [了解更多关于数据隐私的信息](https://www.warp.dev/privacy)
