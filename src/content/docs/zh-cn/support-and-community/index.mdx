## 找到您的空间

### 加入社区

我们的 Slack 社区是分享工作流、修复错误和将想法转化为功能的地方。直接与 Warp 工程师和其他开发者交流。

:::tip
[**加入 Warp 社区 Slack**](https://go.warp.dev/join-preview)
:::

用 Warp 构建了什么东西？代理工作流、CLI 工具、创意终端设置？发到 `#how-do-you-warp` —— 我们会定期展示社区项目。

### 在 GitHub 上与我们一同构建

错误、功能请求以及即将发布的内容。您的投票决定我们的优先级。

[**提交 Issue**](https://github.com/warpdotdev/warp/issues)

Warp 的客户端是开源的。请参阅[为 Warp 做贡献](/support-and-community/community/contributing/)了解完整的贡献路径，包括发起拉取请求、贡献主题和工作流，以及共享 Warp Drive 对象。

### 参加活动

我们全年举办[线上活动](https://luma.com/warpdotdev) —— 产品演示、发布庆祝、社区问答等。一个常驻热门活动：

:::note
**Warp 101 直播** —— 每两周一次，Warp 功能、技巧的现场讲解以及与团队的问答。[**在 Luma 上注册即将举行的活动**](https://luma.com/warpdotdev)
:::

## 计划

* [**Warp Preview**](/support-and-community/community/warp-preview-and-alpha-program/) — 抢先体验实验性功能。您的反馈直接影响发布内容。
* [**推荐好友**](/support-and-community/community/refer-a-friend/) — 将 Warp 推荐给您认为会喜欢它的开发者。赢取主题、周边和礼品卡。
* [**Oz 开源合作伙伴计划**](/support-and-community/community/open-source-partnership/) — 为高影响力开源项目提供免费代理积分。

:::note
**大使计划**

我们正在为想要领导和发展 Warp 社区的开发者构建大使计划。加入[社区 Slack](https://go.warp.dev/join-preview) 了解申请开放时间。
:::
