Warp Preview 是一个早期访问计划，让您可以探索 Warp 最新和最具实验性的功能。它与稳定版独立运行，因此您可以随时回退到可靠的 Warp 版本。

### Warp Preview 的主要特点

* **早期访问** - 在实验性功能正式发布前抢先体验。
* **更快的更新** - 在我们完善新功能时享受频繁的更新和补丁。
* **直接影响** - 您的反馈在塑造 Warp 的未来方面起着关键作用。

要了解更多关于 Warp Preview 的信息，请查看我们的[发布博文](https://www.warp.dev/blog/warp-preview)。

### Warp Preview 入门

1. **下载**：从 [warp.dev/download-preview](https://www.warp.dev/download-preview) 获取 Warp Preview 构建版本。
2. **登录**：使用您的 Warp 账户[登录](/getting-started/quickstart/installation-and-setup/#log-in-to-warp-optional)（Warp Preview 必须登录）。
3. **并排运行**：您可以将 Warp Preview 与稳定的 Warp 安装版本一起保留。

### 重要说明

* **实验性构建** - 预计偶尔会出现错误或不完整的功能。
* **需要登录** - 您必须登录才能使用 Warp Preview。这有助于我们收集反馈、快速诊断关键问题，并确保在您需要支持时可以联系到您。
* **灵活性** - 随时在 Preview 和 Stable 版本之间切换。
* **独特图标** - Warp Preview 使用独特的图标，以区别于稳定版本。

### 提供 Warp Preview 反馈

在[社区 Slack](https://go.warp.dev/join-preview) 中分享反馈、报告错误并讨论 Preview 功能。您也可以[直接从应用发送反馈](/support-and-community/troubleshooting-and-support/sending-us-feedback/#sending-warp-feedback)。
