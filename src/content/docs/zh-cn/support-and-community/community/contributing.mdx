Warp 的客户端在 [`warpdotdev/warp`](https://github.com/warpdotdev/warp) 以 [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) 协议开源，各种形式的贡献都受欢迎——从一行错误报告到完整功能 PR、新主题或能推送到每位 Warp 用户的工作流。如需完整的代码贡献流程，请参阅 [`CONTRIBUTING.md`](https://github.com/warpdotdev/warp/blob/master/CONTRIBUTING.md)。

## 您可以贡献的方式

* **报告错误或请求功能** - 在 [`warpdotdev/warp`](https://github.com/warpdotdev/warp/issues/new/choose) 中[提交问题](https://github.com/warpdotdev/warp/issues/new/choose)，或[浏览现有问题](https://github.com/warpdotdev/warp/issues?q=is%3Aissue+is%3Aopen+sort%3Areactions-%2B1-desc)进行评论或投票。清晰的复现步骤和投票有助于 Warp 确定优先级。
* **贡献代码** - 认领任何标记为 `ready-to-spec` 或 `ready-to-implement` 的问题，然后提交规范或代码 PR。[`CONTRIBUTING.md`](https://github.com/warpdotdev/warp/blob/master/CONTRIBUTING.md) 涵盖了规范格式、测试、`./script/presubmit` 和 PR 模板。
* **构建主题** - 在 [`warpdotdev/themes`](https://github.com/warpdotdev/themes) 提交新的配色方案或改进现有方案。
* **分享工作流** - 将可重用的命令模式添加到 [`warpdotdev/workflows`](https://github.com/warpdotdev/workflows)。合并后的工作流会推送给每位 Warp 用户。
* **发布 Warp Drive 对象** - 从 [Warp Drive](/knowledge-and-collaboration/warp-drive/) 公开分享工作流、Notebook、规则和提示。
* **寻找可处理的问题** - 浏览 [`build.warp.dev`](https://build.warp.dev)，这是 Warp 的代理程序在 `warpdotdev/warp` 上当前处理工作的实时仪表板。用它来发现缺口、避免重复工作，并找出尚未被认领的问题。
* **在社区中帮助他人** - 在 [Warp 社区 Slack](https://go.warp.dev/join-preview) 或 [Discord](https://discord.com/invite/warpdotdev) 中回答问题，并参与 [GitHub Discussions](https://github.com/warpdotdev/warp/discussions) 中的讨论。

## 发送反馈和错误报告

提交错误或功能请求最快的方式是在 Warp 中使用 [`/feedback`](/support-and-community/troubleshooting-and-support/sending-us-feedback/#using-feedback-in-warp) 斜杠命令。它会在不离开终端的情况下起草并提交 GitHub 问题。

其他渠道：

* 直接在 [`warpdotdev/warp`](https://github.com/warpdotdev/warp/issues/new/choose) 中提交问题。
* 按下 `⌘+Shift+F`（macOS）或 `Ctrl+Shift+F`（Windows/Linux）打开应用内反馈对话框。在 macOS 上，您也可以使用 Warp 帮助菜单中的**发送反馈**选项。
* 发送邮件至 [privacy@warp.dev](mailto:privacy@warp.dev) 咨询隐私问题。

关于日志、崩溃报告、CPU 样本和 AI 对话 ID，请参阅[发送反馈和日志](/support-and-community/troubleshooting-and-support/sending-us-feedback/)。

## 报告安全问题

:::danger
请勿公开发布安全漏洞问题。
:::

请发送邮件至 [security@warp.dev](mailto:security@warp.dev)，附上复现步骤、影响范围和任何概念验证。我们将确认收到并协调修复和披露。完整指南请参阅 [`CONTRIBUTING.md`](https://github.com/warpdotdev/warp/blob/master/CONTRIBUTING.md#reporting-security-issues)。

## 行为准则

Warp 的开源仓库遵循 [Contributor Covenant](https://www.contributor-covenant.org/) v2.1。阅读[完整文本](https://github.com/warpdotdev/warp/blob/master/CODE_OF_CONDUCT.md)，或向 [warp-coc@warp.dev](mailto:warp-coc@warp.dev) 报告违规行为。
