### 2024.12.26 (v0.2024.12.18.08.02)

**改进**

* 尝试在 SSH 上 Warpify 不支持的 shell 时，我们现在立即显示错误。

**Bug 修复**

* 修复了调整大小时某些块被追加空行的问题。
* 修复了接受默认自动建议时 AI 上下文消失的问题。

### 2024.12.19 (v0.2024.12.18.08.02)

**新功能**

* 推出：下一条命令！下一条命令使用 AI 根据你的活动终端会话和命令历史建议要运行的下一条命令。访问设置 > AI 将其关闭。
* 在输入编辑器中添加了对块状和下划线样式光标的支持（在禁用 vim 模式时）。

**改进**

* 明确了会话和 Warp Drive 对象的默认权限信息。
* F11（可配置）现在在 Linux 和 Windows 上切换全屏。
* PowerShell 环境变量现在在补全中被识别。
* 光标形状现在对可点击按钮响应更灵敏。

**Bug 修复**

* 未处理按键的字符不再作为输入字符在备用屏幕中处理，例如使用 vim 时。
* 修复了禁用秘密涂抹时复制秘密的问题。
* kubectl 补全现在遵守你的 kubeconfig（通过环境变量或命令行标志指定）。
* 有权限问题的 ssh 命令不应再建议 sudo。
* 修复了 lazygit 进入空白屏幕的问题。
* \[macOS] 修复了更新后 Warp 磁盘映像卷可能无法卸载的 bug。
* \[macOS] 提高了自动更新过程的稳健性。

### 2024.12.13 (v0.2024.12.10.15.55)

**新功能**

* 提示建议可能出现在输入上方，帮助你在可能有帮助的场景中快速激活智能体模式。注意此功能会将活动发送给 LLM 以生成提示。如果你希望关闭，请前往设置 > AI > 智能体模式。
* Warp 现在支持 Claude 3.5 Sonnet 和 Haiku。在智能体模式提示上方的下拉菜单中选择要使用的模型。
* 智能体模式现在可以利用你的 Warp Drive 内容，为你的个人和团队开发者工作流程定制响应。
* Warp 添加了 Shell 选择器——标签栏中"新建标签页"按钮旁边的下拉菜单——用于快速选择系统上可用的 shell。
* 智能体模式现在可以在内置代码编辑器中建议代码更改。
* \[macOS] 你现在可以配置关闭最后一个窗口是否退出应用（在设置 > 功能中）。

**改进**

* 添加了管理 Warp 的 AI 集成和权限的设置。访问设置 > AI 了解更多。
* 单窗口启动配置可以从启动配置面板使用 cmd/ctrl-enter 启动到活动窗口中。
* 你现在可以在 bash 中使用 `PROMPT_COMMAND` 设置 `PS1`。

**Bug 修复**

* 修复了 'Git 未提交文件计数' 提示符标签在 Linux 上的 fish 中无法工作的问题。
* 修复了包含多字节字符的工作流中参数的高亮问题。
* 在启动配置保存弹窗中按 ENTER 现在按预期工作。
* 修复了禁用秘密涂抹时复制秘密的问题。
