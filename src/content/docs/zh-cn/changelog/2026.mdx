* **一致的执行环境** — 配置基于 Docker 的环境（无限制的仓库 + 设置命令），并在隔离的云沙箱中运行智能体。[环境文档 →](https://docs.warp.dev/agent-platform/cloud-agents/environments)
* **从 Web 跟踪智能体** — 在任何浏览器上管理运行、创建计划、配置环境和设置集成，网址为 [oz.warp.dev](https://oz.warp.dev)。
* **基于技能的计划智能体** — 按 cron 计划自动运行智能体，用于代码清理、依赖更新和问题分类。[计划智能体文档 →](https://docs.warp.dev/agent-platform/cloud-agents/triggers/scheduled-agents)
* **默认可编程** — 通过 CLI 编排智能体，并通过 API/SDK 将 Oz 集成到工具和服务中。[API 和 CLI 参考 →](https://docs.warp.dev/reference)

#### Warp 升级

* **智能体模态** — 两种不同的模式：一个干净的终端用于命令，以及一个专用的对话视图用于多轮智能体工作流，具有完整的控制（模型选择、语音、附件）。
* **云端同步的对话** — 你的智能体对话同步到云端并跨设备持久化。通过链接与团队成员分享，在 Web 上查看，或在本地继续。

#### 智能体能力

* **技能** — 可重用的指令集，智能体会从你的项目或主目录自动发现。使用 `/{skill-name}` 调用，或作为计划的云智能体运行以实现可重复的自动化。[技能文档 →](/agent-platform/capabilities/skills/)
* **计算机使用** — 智能体可以在沙盒云容器中与桌面环境交互——截图、点击、输入和测试 UI 更改。[计算机使用文档 →](/agent-platform/capabilities/computer-use/)
