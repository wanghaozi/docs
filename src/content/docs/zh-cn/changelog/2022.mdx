### 2022.12.15 (v0.2022.12.13.08.04)

**新功能**

* 你现在可以使用鼠标重新排序和拖拽标签页！

**Bug 修复**

* 欢迎 Block 现在在使用 Fish shell 时也能正常显示。
* AI 命令搜索不再因通过 `#` 前缀打开时的多字节字符而崩溃。
* Warp 在已删除或无法访问的目录中启动新会话时不再崩溃。
* 修复了 'k9s' 和 'less' 等全屏应用中的渲染问题和挂起。
* 添加了登录失败通知。

### 2022.12.06 (v0.2022.12.06.08.03)

**新功能**

* 用户现在可以选择退出遥测（应用分析和崩溃报告）。
* 添加了"跟踪 Warp 网络日志"工作流，用于查看所有应用网络活动的日志。

**Bug 修复**

* mitmproxy 等全屏 CLI 命令现在正确跨越整个视图。
* 改进了设置中功能页面的样式和组织。
* 输入时补全菜单在生成新结果时关闭。
* 为根目录添加了隐藏的补全结果。
* 当一个会话包含多个块时，Warp 现在消耗更少的内存。
* 修复了 SSH 中日志被插入输入的问题。

### 2022.12.02 (v0.2022.11.29.08.03)

**新功能**

* 用户现在可以选择退出遥测（应用分析和崩溃报告）。
* 添加了"跟踪 Warp 网络日志"工作流，用于查看所有应用网络活动的日志。

**Bug 修复**

### 2022.12.01 (v0.2022.11.29.08.03)

**新功能**

* Warp 现在支持在备用屏幕中使用查找栏！`CMD-F` 现在可以在 vim、less 和其他备用屏幕应用中打开查找！

**Bug 修复**

* 尊重 Warp 配置目录中的符号链接（用于主题和工作流）。
* 修复了设置 RPROMPT 时输入编辑器中出现不需要的文本的问题。
* 修复了 Emoji 编辑器无法正常工作的问题。
* 修复了使用 Unicode 十六进制输入键盘时可能发生的崩溃。
* 修复了 Escape 键绑定未关闭资源中心的问题。
* 向后/向前移动一个单词的键位现在可被覆盖。
* 修复了在输入编辑器中悬停多字节文本时的崩溃。
* 修复了 SSH 包装器的 "command not found: sed" 和 "command not found: tr" 问题。
* 修复了 Tab 补全和命令搜索可能同时可见的问题。

### 2022.11.15 (v0.2022.11.14.14.55)

**新功能**

* 命令搜索：Ctrl-R 打开一个面板，你可以在一个地方搜索你的历史记录、工作流和其他命令执行相关项。
* 粘性命令标题：Warp 现在将 Block 的提示/命令部分固定在屏幕顶部；点击可滚动到 Block 顶部。可通过设置 > 功能 > 显示粘性命令标题切换。
* Warp 的输入编辑器现在支持软换行；长命令现在完全可见！

**Bug 修复**

* Warp 现在在包装的 SSH 会话中正确设置 TERM_PROGRAM 环境变量。
