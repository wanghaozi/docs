### 2021.12.22 (v0.2021.12.20.09.04)

**新功能**

* 重新打开 Warp 时会恢复窗口、标签页和窗格。恢复块内容即将推出！
* Warp 现在支持 300 多个命令的自动补全，并通过使用 Fig 的补全规范提供有关现有命令的更多信息
* Git 别名现在已包含在补全菜单中 - [210](https://github.com/warpdotdev/warp/issues/210)
* 使用 CMD-[ 和 CMD-] 切换到下一个窗格和上一个窗格 - [392](https://github.com/warpdotdev/warp/issues/392)
* 使用 PG-UP 和 PG-DOWN 滚动块列表 - [370](https://github.com/warpdotdev/warp/issues/370)
* 从 Finder 复制文件目录并粘贴到 Warp - [514](https://github.com/warpdotdev/warp/issues/514)
* 选中最后一个 Block 时，可以使用 CMD-DOWN 键重新聚焦输入编辑器
* 向下箭头滚动到最后一个块的底部

**Bug 修复**

* 将选中的文本复制到剪贴板时，每个选中的字符都会创建一个新条目 - [504](https://github.com/warpdotdev/warp/issues/504)
* 需要额外按一次退格键才能退出 CTRL-R / 历史菜单 - [427](https://github.com/warpdotdev/warp/issues/427)
* VIM 性能改进——我们已取得进展，但希望获得更多关于卡顿的示例案例

**Mac 菜单栏更新（窗口）**

* 缩放
* 最小化
* 将窗口平铺到屏幕左侧（默认）
* 将窗口平铺到屏幕右侧（默认）
* 移动到 X 屏幕（默认）
* 进入全屏（默认）
* 全部前置
