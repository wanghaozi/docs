### 2025.12.17 (v0.2025.12.17.17.17)

**改进**

* Warp 现在在信用透明度页脚中指定不同模型用于哪些用途。
* 你可以选择分叉对话是在分屏窗格还是新标签页中打开。
* `warp mcp list`、`warp environment list` 和 `warp agent profile list` 现在支持纯文本和 JSON 输出。
* MCP 服务器配置现在显示在集成详情中（即 `warp integration list`）。
* 添加了在集成中配置 MCP 服务器的支持。

**Bug 修复**

* 修复了 Oz CLI 运行可能卡在尝试运行拒绝列表中的命令的 bug。

### 2025.12.10 (v0.2025.12.10.08.12)

**改进**

* 在代码审查中添加了"初始化代码库"按钮，当你在未初始化的仓库中时会显示，使设置代码库索引和 LSP 更容易。
* 在模型选择器中添加了新的子菜单，用于选择推理模型的推理级别。
* 为 Vue 模板文件添加了语法高亮。
* 添加了使用 `--model` 标志为智能体、集成和计划智能体指定自定义模型的支持。
* 添加了对 MCP Streamable HTTP 或 SSE 服务器连接中自定义 HTTP 头的支持。
* 添加了 `/conversations` 斜杠命令，带有时钟回退图标，用于打开对话历史面板。
* Warp 集成将更主动地发出智能体被阻塞的信号。

**Bug 修复**

* 修复了在 `设置 > 结算和使用情况` 中，对于启用自动充值的团队，信用面额未设置为正确值的 bug。
* 当"选择在 Warp 中打开文件的布局"设置为"新标签页"时，代码编辑器现在在活动标签页的右侧打开。
* 修复了不使用备用屏幕缓冲区的应用（例如 Radare2）的鼠标报告。

### 2025.12.03 (v0.2025.12.03.08.12)

**改进**

* Oz CLI 现在在智能体尝试采取被禁止的操作时显示更详细的信息。
* 允许从项目浏览器的文件路径拖放到活动的终端命令中（如 claude code 和 gemini），以引用文件和文件夹。

**Bug 修复**

* 修复了使用 Warpify 子 shell 或传统（非 tmux）SSH Warpify 实现时可能导致无界内存增长的问题。
* 修复了 Warpify 子 shell 中出现 `comm` 错误的 bug。
* \[Windows] 修复了"在代码编辑器中查找"的键位。现在是 `CTRL-SHIFT-F`，可在设置 > 键盘快捷键中配置。
* 确保 Oz CLI 在 macOS 上自动可用。
* 修复了在对 Warp Drive 中的计划执行操作时，提示消息显示"笔记本"而不是"计划"的问题。

### 2025.11.19 (v0.2025.11.19.08.12)

**新功能**

* MCP 服务器配置现在可以与团队中的其他人共享。你可以通过最小配置安装团队共享的服务器。
* Warp 现在为常见服务（如 Github 和 Linear）提供开箱即用的 MCP 服务器，可一键安装和运行。
* 查找现在在代码审查窗格中工作。

### 2025.11.18 (v0.2025.11.18.12.24)

**新功能**

* [完整终端使用](/agent-platform/capabilities/full-terminal-use/)：让智能体像你一样使用终端：与 REPL、调试器和全屏应用（如 `top`）进行交互。Warp 是市场上唯一具有完整终端使用能力的产品。
* [`/plan`](/agent-platform/capabilities/planning/)：在 Warp 中进行规范驱动的开发。与智能体协作商定一个可以保存、版本化甚至附加到 PR 与团队成员共享的实现计划。
* [交互式代码审查](/agent-platform/local-agents/interactive-code-review/)：像审查团队成员的代码一样直接在 Warp 中审查智能体的代码，并让智能体处理你的评论。
* [Slack 和 Linear 集成](https://docs.warp.dev/agent-platform/cloud-agents/integrations)：让智能体从你已使用的工具开始工作，跟踪他们的进度，并通过实时会话共享接管控制权。
* Warp 的智能体现在可以[搜索网络](/agent-platform/capabilities/web-search/)以检索相关信息（如相关）。此功能可通过智能体配置文件进行配置。

* Warp Drive 环境变量现在支持 Windows 版 Warp（PowerShell、Git Bash 和 WSL）。

**新功能**

* 修复了俄语在 PowerShell 上的输入问题。
