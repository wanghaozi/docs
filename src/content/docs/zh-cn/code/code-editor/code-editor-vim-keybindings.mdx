Warp 内置的代码编辑器支持原生 Vim 键位，用于键盘驱动的导航和编辑。启用 Vim 模式，可以直接在 Warp 中使用熟悉的动作、文本对象、可视模式、寄存器和编辑命令，无需切换到外部编辑器。

## 关于 Vim 键位

Vi 系列程序（包括 Vim 和 Neovim）是模态文本编辑器，支持键盘驱动的文本编辑。Vi 风格的键位因其在导航和操作代码时的速度和精度而在开发者中特别流行。Warp 的[代码编辑器](/code/code-editor/)现在包含对 Vim 键位的原生支持（也称为 Vim 模式），直接在编码工作流中提供熟悉的编辑体验。

### 如何启用 Vim 键位

代码编辑器中的 Vim 模式使用与输入编辑器相同的设置开关。要启用：

* 通过[命令面板](/terminal/command-palette/)，搜索"Vim 键位"。
* 通过**设置** > **功能** > **文本编辑**，切换"使用 Vim 键位编辑代码和命令"。

与输入编辑器不同，代码编辑器中的 Vim 实现默认以普通模式启动。

### 自定义键位

目前，Warp 仅支持默认的 Vim 键位。

一个例外是退出插入模式的键盘快捷键，可以在**设置** > **键盘快捷键** > **退出 Vim 插入模式**下重新绑定，或通过[命令面板](/terminal/command-palette/)搜索"退出 Vim 插入模式"。

## 支持的键位

以下是 Warp 目前已实现的 vim 功能列表。

### 移动

请参阅 [Vim 文档：移动](https://vimdoc.sourceforge.net/htmldoc/motion.html)了解详细信息。

#### 基本

| 命令                         | 描述                   |
| ---------------------------- | ---------------------- |
| `h`, `j`, `k`, `l`           | 单字符移动             |
| `<space>`, `<backspace>`     | 带换行的单字符移动     |
| `w`, `W`, `b`, `B`, `e`, `E` | 单词移动               |
| `ge`, `gE`                   | 上一个单词的结尾       |
| `$`                          | 行尾                   |
| `0`                          | 行首                   |
| `^`                          | 行的第一个非空白字符   |
| `%`                          | 跳转到匹配的括号       |
| `[`, `]`                     | 上一个/下一个不匹配的括号 |
| `_`                          | 当前行的开始           |
| `+`                          | 下一行的第一个非空白字符 |
| `-`                          | 上一行的第一个非空白字符 |
| `{`, `}`                     | 上一个/下一个段落      |

#### 多行相关

| 命令        | 描述               |
| ---------- | ------------------ |
| `gg`, `G`  | 跳转到第一行/最后一行 |

### 编辑

| 命令       | 描述                                       |
| ---------- | ------------------------------------------ |
| `r`        | 替换光标下的字符                           |
| `d`, `D`   | 删除一个范围或对象                         |
| `c`, `C`   | 修改一个范围或对象（删除，然后进入插入模式）|
| `s`, `S`   | 替换（类似于修改，但只能在光标处删除）     |
| `x`, `X`   | 删除光标下的字符                           |
| `y`, `Y`   | 复制到剪贴板                               |
| `p`, `P`   | 从剪贴板粘贴                               |
| `u`, `⌃r`  | 撤销，重做                                 |
| `~`        | 切换光标下的大小写                         |
| `gu`       | 光标下小写（可视模式中为 `u`）            |
| `gU`       | 光标下大写（可视模式中为 `U`）            |
| `J`        | 合并当前行和下一行                         |
| `.`        | 重复上次编辑                               |
| `gcc`      | 切换当前行的注释                           |
| `gc`       | 切换可视选择的注释                         |

请参阅 [Vim 文档：编辑](https://vimdoc.sourceforge.net/htmldoc/editing.html)了解详细信息。

#### 文本对象

| 命令             | 描述                             |
| ---------------- | -------------------------------- |
| `i`              | 内部（排除文本对象中的定界符）   |
| `a`              | 周围（包括文本对象中的定界符）   |
| `w`, `W`         | 空格分隔的字符串（单词）         |
| `"`, `'`, \`\`\` | 引号分隔的字符串                 |
| `(`, `{`, `[`    | 括号/方括号内的字符串            |

请参阅 [Vim 文档：文本对象](https://vimdoc.sourceforge.net/htmldoc/motion.html#text-objects)了解详细信息。

### 搜索

#### 字符搜索

| 命令               | 描述                             |
| ------------------ | -------------------------------- |
| `t`, `T`, `f`, `F` | 在行上查找下一个/上一个匹配字符  |
| `;`                | 沿相同方向重复上次字符搜索       |
| `,`                | 沿相反方向重复上次字符搜索       |

请参阅 [Vim 文档：左右移动](https://vimdoc.sourceforge.net/htmldoc/motion.html#f)了解详细信息。

#### 常规搜索

与 Vim 不同，常规搜索命令不在缓冲区中搜索。相反，它们打开 Warp 的原生命令搜索。

| 命令               | 描述                |
| ------------------ | ------------------- |
| `/`, `?`, `*`, `#` | 打开 Warp 命令搜索 |

### 模式切换

| 命令 | 描述                               |
| ---- | ---------------------------------- |
| `i`  | 在光标前插入文本                   |
| `I`  | 在行首第一个非空白字符前插入文本   |
| `a`  | 在光标后追加文本                   |
| `A`  | 在行尾追加文本                     |
| `o`  | 在光标下方新起一行并插入文本       |
| `O`  | 在光标上方新起一行并插入文本       |
| `v`  | 可视字符模式                       |
| `V`  | 可视行模式                         |

请参阅 [Vim 文档：插入](https://vimdoc.sourceforge.net/htmldoc/insert.html#insert)和 [Vim 文档：可视模式](https://vimdoc.sourceforge.net/htmldoc/visual.html#visual-mode)了解详细信息。

### 寄存器

| 命令 | 描述       |
| ---- | ---------- |
| `"`  | 寄存器前缀 |

Warp 目前支持以下寄存器：

| 寄存器名称         | 描述                       |
| ----------------- | -------------------------- |
| `a`–`z`, `A`–`Z` | 命名寄存器                 |
| `+`              | 系统剪贴板                 |
| `*`              | 系统剪贴板                 |
| `"`              | 未命名寄存器，包含上次删除或复制的内容 |

请参阅 [Vim 文档：寄存器](https://vimdoc.sourceforge.net/htmldoc/change.html#registers)了解详细信息。
