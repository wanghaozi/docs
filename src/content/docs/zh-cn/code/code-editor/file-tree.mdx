文件树是 Warp 内置的项目浏览器，用于在终端旁边浏览、打开和管理文件。它会自动反映你的项目结构，并支持上下文菜单操作，如将文件附加为智能体上下文、复制路径和创建新文件。

![Warp 的原生文件树，在左侧面板中显示项目的文件和文件夹结构。](../../../../../assets/terminal/filetree-main.png)

Warp 包含一个**原生文件树**，使探索和管理项目文件变得容易。文件树在任何目录中都可用，它会自动反映你的项目结构——文件被添加、删除或更改时实时更新。

:::note
当 Warp 的 [SSH 扩展](/terminal/warpify/ssh/#installing-the-ssh-extension)安装在远程主机上时，文件树也可在 macOS 和 Linux 上的 SSH 会话中使用。
:::

### 打开文件树

你可以从左侧的工具面板打开文件树：

* **工具面板**：点击工具侧边栏按钮，然后打开文件树标签页（面板中的第一个标签页）。
* 按 `CMD + \` 打开左侧面板，然后在**设置** > **键盘快捷键**中为文件树（和 Warp Drive）分配你自己的快捷键。

![从 Warp 的工具面板侧边栏打开文件树。](../../../../../assets/terminal/file-tree-project-explorer-tools-panel.png)

:::note
Warp 支持常见文件类型的图标。如果某个文件类型缺少图标，请[提交 GitHub issue](https://github.com/warpdotdev/Warp/issues)，以便我们审查并添加支持。
:::

### 浏览和打开文件

点击文件可直接在 Warp 的[**原生代码编辑器**](/code/code-editor/)中打开，你可以在单独的窗格或标签页中查看和编辑代码。

## 文件和文件夹操作

右键点击任何**文件**会打开一个包含几个有用选项的上下文菜单：

* **在新窗格中打开**：在并排窗格中打开文件。
* **在新标签页中打开**：在新标签页中打开文件。
* **附加为上下文**：将文件插入到智能体提示中，以便智能体分析或引用。
* **复制路径**：复制绝对文件路径。
* **复制相对路径**：复制相对于当前工作目录的路径。

右键点击任何**文件夹**会打开一个包含以下选项的上下文菜单：

* **创建新文件**：直接从树中添加新文件。

    ![在文件树中通过文件夹的右键上下文菜单创建新文件。](../../../../../assets/terminal/file-tree-new-file.png)
* **附加为上下文**：将选中的文件插入到智能体提示中，以便智能体分析或引用。
* **复制路径**：将绝对文件路径复制到剪贴板。
* **复制相对路径**：复制相对于当前工作目录的路径。
