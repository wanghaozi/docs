### 1. 为什么多个代理很重要

有时你需要同时处理多个编码任务——修复 PR、添加功能、调试构建——而不丢失上下文。\
\
Warp 让你可以在一个工作区内同时运行多个代理任务。

---

### 2. 工作原理

每个代理在自己的线程中运行，具备：

* 进度跟踪
* 阻塞或完成时的通知
* 独立的命令历史

因为 Warp 是一个桌面应用，它可以在代理完成或需要审查时发送系统通知。

---

### 3. 示例：回滚 PR 和编辑快捷键

Ben 使用语音模式快速启动任务。

提示示例：\
"找到我们向 UDI 输入添加键盘快捷键的那个 PR 并将其回滚。"

他粘贴 PR 编号，代理：

* 定位相关差异
* 自动回滚更改
* 推送到正确的分支

任务完成时 Warp 会通知他。

然后，他运行另一个提示：

提示示例：\
"将键盘快捷键改为 `Cmd + Shift + I`。"

Warp 修改 `input.rs`，预览差异，Ben 直接从 Warp 应用更改。

---

### 4. 管理多个任务

你可以并发代理之间切换：

* 每个任务出现在任务列表面板中
* 已完成、已取消和正在运行的任务带有颜色编码
* 任务被阻塞时会出现 Toast 通知

一旦你信任代理的方向，你甚至可以快进代理以自动批准所有代码差异。

---

### 5. 并行上下文

在另一个仓库中，Ben 通过不同的代理添加了一个新的 Eval 测试：

提示示例：\
"创建一个 Python hello world 函数并验证它打印出 'Hello World'。"

Warp 的第二个代理：

* 定位正确的文件
* 编写测试代码
* 验证执行

同时，第一个代理继续处理键盘快捷键任务。

---

### 6. 查看所有活动代理

打开代理模式仪表板查看：

* 活动任务
* 已完成任务
* 日志和输出

你可以在运行中优化或取消任务，或者切回手动命令。

有关涵盖任务分解、工作树、云端编排、验证和审查移交的工作流导向设置指南，请参阅[如何运行多个 AI 编码代理](/guides/agent-workflows/how-to-run-multiple-ai-coding-agents/)。
