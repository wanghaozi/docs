Warp 让你可以直接在应用内查看、编辑和完善 AI 生成的代码差异。\
这使得调试和错误修复工作流程变得快速、透明且具有交互性。

---

### 1. 启动代理任务

当你启动一个代理任务时，Warp：

1. 使用你的提示词和上下文
2. 构建任务列表
3. 使用以下工具搜索你的代码库：
   * Grep
   * 代码库嵌入
   * 语义搜索

Warp 会逐步显示进度，包括正在搜索的内容以及正在修改的文件。

---

### 2. 审查差异

Warp 会为每个提议的变更生成差异。\
你可以：

* 接受变更
* 使用后续提示词进行优化（`Cmd + R`）
* 或者在内联编辑器视图中直接编辑代码

该编辑器视图的工作方式类似于轻量级 IDE——非常适合在应用之前进行快速修正。

---

### 3. 应用或跳过更改

一旦你对差异满意：

* 点击 Apply Changes 接受它
* 或者点击 Fast-Forward 让 Warp 自动继续执行后续的修复序列

你可以在设置 → AI → 自主性中全局控制这种自主程度。

---

### 4. 编译和验证修复

应用更改后，你可以立即测试构建，例如：

```bash
cargo run
```

Warp 会监控编译过程、验证结果，并自动运行后续检查。

---

### 5. 可视化验证

在这个示例中，错误涉及复选框在 UI 中未被正确识别。\
\
在代理修复之后：

* 复选框逻辑现在按预期工作
* 模型选择器正确切换
* UI 行为符合预期
