### 1. 从命令面板开始

打开命令面板：

* Mac：`Cmd + P`
* Windows/Linux：`Ctrl + Shift + P`

然后输入"Disable"即可看到所有 UI 开关的完整列表。\
Warp 会提供让你快速隐藏功能和视觉元素的选项。

---

### 2. 要禁用的关键 UI 开关

#### 内联和 AI 功能

* 禁用自动建议 → 移除内联代码提示。
* 禁用主动 AI → 隐藏建议代理查询的幽灵提示。
*禁用补全菜单 → 防止弹出补全建议。
* 禁用语音输入 → 隐藏麦克风图标。

#### 界面与布局

* 禁用块分割线 → 移除命令之间的水平线。
* 禁用标签指示器 → 隐藏标签栏上的彩色状态标记。
* 禁用非活动面板变暗 → 保持所有拆分面板亮度一致。
* 禁用 VIM 状态栏 → 如果你不使用 VIM 模式，移除 VIM 指示器。

---

### 3. 选择更简洁的主题

视觉干扰也可能来自颜色。\
尝试从命令面板切换到更柔和的主题：

1. 再次打开命令面板（`Cmd + P`）
2. 输入"Theme"
3. 选择一个色调更柔和的主题——例如：
   * Adeberry → 平静、灰色、简约的美学
   * Classic Dark → 熟悉且专注

一致的、中性的色调让 Warp 感觉更轻量，对眼睛也更友好。

---

### 4. 切换到经典提示符

Warp 的通用提示符非常适合 AI 工作流——它支持：

* 斜杠命令
* 语音输入
* 图像上下文
* 代理模式

但如果你只想要一个行为像经典 shell 的终端，可以切换到经典提示符：

1. 打开命令面板 → 搜索"Prompt"
2. 选择 Classic Prompt
3.（可选）打开提示符定制器来切换标签：
   * 只保留你需要的（例如，文件路径）
   * 隐藏其他所有内容（分支名称、上下文图标等）

这能即时赋予 Warp 复古、文本优先的外观——没有杂乱，没有干扰。

---

### 5. 减少标签栏可见性

你可以让标签栏仅在悬停时显示：

* 打开设置 → 外观
* 启用"在悬停时显示标签"

这能保持工作区专注，同时在需要时仍可访问标签。
