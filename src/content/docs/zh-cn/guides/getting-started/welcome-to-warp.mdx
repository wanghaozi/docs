### 1. 欢迎使用 Warp

打开 Warp 时，你会看到一个熟悉的界面——命令行界面——但它远不止是一个传统终端。\
\
Warp 是一个智能开发环境（ADE），这意味着你的主要交互方式是通过向代理发送提示词。

你仍然可以像使用任何终端一样使用 Warp：

```bash
ls
pwd
```

Warp 会完全按预期执行这些命令。\
\
但是，当你输入自然语言时——比如"描述我打开的 git 变更"——Warp 会将其解释为启动代理的提示词。

---

### 2. 基于提示词的编码

当你用普通英语提问时，Warp 的代理会自动：

* 收集相关上下文（你的仓库、文件或命令输出）
* 运行所需的任何命令
* 返回结构化答案或执行请求的操作

示例：

> "描述我打开的 git 变更。"

Warp 的代理会审查你当前的分支，在后台运行 git 命令，并总结待处理的变更。

---

### 3. 融合终端与代理工作流

Warp 的妙处在于它如何无缝地融合传统 CLI 工作流与 AI 驱动的自动化。\
你可以：

* 像普通 shell 一样输入命令
* 或者提示代理完成调试、代码审查或环境设置等操作

无需在应用之间切换上下文——一切都在同一个环境中完成。
