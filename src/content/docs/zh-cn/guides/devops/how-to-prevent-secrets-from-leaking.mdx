了解如何使用 Warp 的机密编辑和规则系统保护凭据和敏感数据。

<VideoEmbed url="https://youtu.be/2ECPFKtQpVk?si=HHw14Tqj-QyHeByX" />

本教程展示如何使用 Warp 的**规则**防止代理或协作者在编码或共享输出时暴露敏感信息。无论你是结对编程、直播还是审查代码，Warp 都可以在代理看到机密之前自动将其编辑。

<Steps>

1. #### 问题

   AI 助手经常在生成的代码块中回显 API 密钥、令牌或凭据。\
   在协作或共享屏幕时，这可能会公开暴露机密信息。

2. #### 规则设置

   在 Warp 中定义一个简单的规则，指示代理在输出或命令中**绝不显示机密**。

   ```
   Rule: Protect Secrets
   Behavior:
   - Never include or reveal secrets when generating code or commands.
   - Automatically redact sensitive strings before showing output.
   ```
   :::note
   启用 Warp 的内置机密编辑：

   设置 → AI → 启用机密编辑

   这会在代理或输出日志访问之前自动屏蔽敏感值。
   :::

3. #### 好处

   * 保护 API 密钥和凭据免于暴露
   * 确保直播和演示安全
   * 与结对编程或 AI 调试无缝协作

</Steps>
