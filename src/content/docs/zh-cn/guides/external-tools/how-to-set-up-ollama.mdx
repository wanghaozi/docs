### 1. 检查你的系统规格

在本地运行大型语言模型（LLM）之前，请确认你的硬件能够处理。

示例配置：

* Mac：64GB 统一内存——适合较大的模型，但吞吐量较低。
* Windows（NVIDIA RTX 5090）：32GB VRAM——性能优秀，但受限于 VRAM 容量。

> 🧠 经验法则：每十亿参数大约需要 1GB VRAM。

---

### 2. 运行你的第一个模型

在本地运行模型：

> ollama run gpt-oss

例如：

* 尝试 GPT-OSS 20B（需要 ≥16GB VRAM，支持工具调用）。
* 然后尝试 Mistral 8B 作为更快、更小的替代方案。

并排比较它们的性能和质量。\
使用 Warp 轻松监控 GPU 使用率和模型响应时间。

---

### 3. 理解模型术语

以下是为选择正确的本地模型提供的快速词汇表：

| 术语 | 含义 |
| ---------------- | ------------------------------------------------------------------ |
| **思考** | 模型在回答之前"思考"；更适用于复杂推理。 |
| **工具** | 模型可以使用外部工具（例如网络搜索）。 |
| **视觉** | 可以处理并响应图像。 |
| **嵌入** | 将文本转换为数值形式，用于搜索或 RAG 流程。 |
| **量化** | 通过降低精度（例如 4 位）减少内存使用。 |

---

### 4. 将 Ollama 集成到你的应用中

大多数应用使用兼容 OpenAI 的 API，因此集成很简单。

1. 在 Warp 中打开你的应用代码。
2. 找到 OpenAI 客户端初始化部分。
3. 将基础 URL 替换为 Ollama 的地址。
4. 更新你的 API 密钥和模型名称。

Warp 帮助你直接从终端快速定位、编辑和测试集成。

---

### 6. 自定义模型行为

拉取并修改一个模型。

然后将其保存为具有新设置（如温度或系统提示）的自定义模型。

使用 Warp 自动生成模型文件。\
这为该任务添加了结构化的系统提示——立即可用。
