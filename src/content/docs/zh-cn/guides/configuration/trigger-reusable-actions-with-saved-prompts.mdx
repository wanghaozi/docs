### 1. 自动化提交

当处理 PR 时，无需输入冗长的提交信息，你可以使用已保存提示。

Warp 的代理：

* 运行 `git diff` 并总结更改
* 生成清晰的提交信息
* 自动推送到你的分支

你可以在 Warp Drive → 团队提示中查看已保存提示，它显示：

* 谁创建的
* 上次使用时间
* 已运行次数

因为它保存在团队驱动中，任何人都可以复用。

---

### 2. 使用提示审查代码

在创建 PR 之前，你可以运行另一个已保存提示。

该代理：

* 读取你当前的分支
* 审查差异
* 突出逻辑或风格问题
* 建议改进

示例输出：

> "检测到逻辑错误——异步处理程序中存在潜在的竞态条件。"

Warp 在打开 PR 之前就自动发现真正的问题——节省时间并减少与审查者的来回沟通。

---

### 3. 自动打开拉取请求

当你的代码看起来干净后，触发你的最终已保存提示。

Warp 将：

* 生成 PR 标题和描述
* 推送分支
* 在 GitHub 上打开 PR
* 如果在提交信息中找到相关问题，甚至可以链接它们

---

### 4. 共享和团队使用

所有已保存提示都保存在你的团队 Warp Drive 中，这意味着：

* 任何人都可以发现并运行它们
* 你可以参数化或修改它们
* 使用历史和创建者信息可见

这使得团队可以轻松标准化常见操作，如代码审查、部署或构建运行。
