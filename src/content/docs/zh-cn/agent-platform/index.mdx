title: Agent 概述

  Oz 是云 Agent 的编排平台，为交互式和自主 Agent 提供开发工作流的能力。
---

Warp 包含 **Oz**，为所有 Warp 的 Agent 提供支持的编排平台。Oz 在 Warp 内部本地运行交互式 Agent 以提供实时编码帮助，并在云端部署自主 Agent 以提供后台自动化、事件驱动的工作流以及跨仓库和团队的并行执行。

使用 Oz，您可以：

* 在 Warp 中运行交互式 Agent 对话以提供实时编码帮助
* 部署从触发器、计划或集成在云端运行的自主 Agent
* 跨机器、仓库和团队同时协调多个 Agent
* 跟踪、审计和共享 Agent 活动，对运行内容和结果具有完全可见性

## 关键能力

* [**本地 Agent**](/agent-platform/local-agents/overview/) - 嵌入 Warp 的交互式 Agent
* [**第三方 CLI Agent**](/agent-platform/cli-agents/overview/) - 在 Warp 中使用 Claude Code、Codex、OpenCode 等
* [**云 Agent**](/agent-platform/cloud-agents/overview/) - 响应系统事件、计划或集成在后台运行的自主 Agent
* [**集成**](/agent-platform/cloud-agents/integrations/) - 将外部系统事件连接到自主 Agent 执行
* [**Oz Platform**](/agent-platform/cloud-agents/platform/) - 为 Oz 提供支持的基础设施
