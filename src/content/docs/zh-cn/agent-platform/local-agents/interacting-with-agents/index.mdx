Warp 中的 Agent 对话是绑定到终端会话的多轮交互。继续先前线程与后续操作，管理对话历史，从代码块和文件附加上下文，以及在窗口、标签或窗格中同时运行多个对话。

## 对话

从概念上讲，对话是 AI 查询和代码块的序列。对话绑定到会话，您可以在不同窗口、标签或窗格中同时运行多个 Agent 模式对话。

### 停留在对话中（后续）

默认情况下，如果在 Agent 模式中交互后立即发送 AI 查询，查询将作为**后续**发送到当前对话。

### 管理对话

您可以通过**对话菜单**（`CMD + Y`（macOS）/ `CTRL + SHIFT + Y`（Windows/Linux））查看先前对话或开始新对话。

### 开始新对话

Warp 在几种情况下自动创建新对话。您也可以随时手动开始新对话。

## 上下文窗口管理

Warp 提供**上下文窗口使用指示器**来帮助您跟踪。当使用量低于 20% 时，不显示指示器。随着接近限制，指示器变红。超出限制后，Warp 自动总结对话。

## 对话分割

Warp 自动检测查询何时切换到新主题，并建议开始新对话。

## 对话面板

**对话面板**在窗口左侧，是浏览和切换 Agent 对话的主页。面板分为 Active 和 Past 两个下拉部分。
