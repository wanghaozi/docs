Warp 允许您**分叉对话**以创建继承现有对话所有上下文、消息和历史的新线程。当您想在不影响原始对话的情况下分支到新方向时，这很有用。

### 对话分叉如何工作

* 分叉对话时，新线程以与原始线程相同的上下文和历史开始。
* 分叉对话中的任何后续操作**不会**影响原始对话。同样，在原始对话中继续不会改变分叉。
* 分叉对话的行为与任何其他对话相同：您可以将其移动到新窗口、窗格或标签。
* 您选择的模型和执行配置文件在分叉对话中保留。

### 如何分叉对话

有五种方式分叉现有对话：

#### 1. 从命令面板 - `CMD + Y`（macOS）/ `CTRL + SHIFT + Y`（Windows/Linux）
#### 2. 从最新 AI 响应块的页脚 - 点击分叉按钮
#### 3. 使用 `/fork` 斜杠命令
#### 4. 使用 `/fork-and-compact` 斜杠命令 - 分叉并自动压缩
#### 5. 使用 `/fork-from` 斜杠命令 - 从特定点分叉

### 从对话中任何位置分叉

**右键点击**任意 Agent 响应块，选择"从此处分叉对话"，创建包含直到并包括该响应的所有内容的新对话。
