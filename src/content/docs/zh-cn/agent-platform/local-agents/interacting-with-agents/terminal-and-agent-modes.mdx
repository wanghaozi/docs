Warp 提供两种不同模式：用于运行 shell 命令的干净终端，以及用于与 Oz（Warp 的 Agent）进行多轮交互的专用对话视图。终端模式默认保持界面最小化，而 Agent 模式呈现完整的控制功能，包括模型选择、语音输入、图像附件和对话管理。

<VideoEmbed url="https://youtu.be/J715YW5VC18" />

## 关键术语

* **终端会话** - 运行命令的 shell 环境。打开 Warp 时的默认模式。
* **Agent 对话** - 与 Oz 的多轮交互。对话保持跨轮次的上下文，具有专用视图和更丰富的控制。

## 为什么有两种模式

将终端和 Agent 工作流分离到不同的上下文中：

* **默认干净终端** - 运行命令时输入最小化
* **专用对话视图** - 多轮工作流具有完整控制功能
* **明确的模式切换** - 当前模式清晰可见

## 终端模式（默认）

终端模式是打开新标签或窗格时的默认模式。消息栏提供上下文指导。

## Agent 对话视图（扩展 UI）

带有更丰富控制的专用对话视图，包括模型选择、语音输入、图像附件和对话管理。

## 自动检测

自动检测帮助 Warp 将每个输入解释为 shell 命令或 Agent 请求。您可以在设置中分别控制终端模式和 Agent 对话视图的自动检测。

## 导航对话

Warp 包括用于浏览和管理 Agent 对话的**对话面板**。

## 键盘快捷键

在对话视图中按 `?` 显示/隐藏完整快捷键面板。

### 导航和模式切换
* 开始新 Agent 对话：`⌘↩` (macOS) / `Ctrl+Shift+Enter`
* 开始新云 Agent 对话：`⌥⌘↩` (macOS) / `Ctrl+Alt+Enter`
* 退出对话：`esc`
* 覆盖自动检测：`⌘I` (macOS) / `Ctrl+I`
