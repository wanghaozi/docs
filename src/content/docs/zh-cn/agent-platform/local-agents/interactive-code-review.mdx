交互式代码审查让您审查 Agent 生成的代码，在特定行上留下内联评论，批处理您的反馈，并在单次传递中将所有请求的更改发送给 Agent。它适用于 Warp 的原生 Agent 和受支持的第三方 CLI Agent，如 Claude Code 和 Codex。

## 概述

交互式代码审查让您审查、注释和优化任何受支持 Agent 生成的代码，无论是 Warp 的原生 Agent 还是在 Warp 中运行的第三方 CLI Agent。您可以检查差异、留下内联评论、批处理反馈，并在单次传递中将所有请求的更改发送回 Agent。

## 受支持的 Agent

交互式代码审查适用于在 Warp 中运行的任何受支持 Agent：
* **Warp 的原生 Agent** — Agent 模式中的内置 Agent
* **第三方 CLI Agent** — Claude Code、OpenAI Codex、OpenCode 等

## 留下内联评论

选择任何更改的行或块并添加描述想要调整内容的评论。

## 批处理评论并一次性提交

在提交前添加任意数量的评论。Agent 收到您的完整反馈批次，在一次迭代中应用更改，并返回更新后的差异以供验证。
