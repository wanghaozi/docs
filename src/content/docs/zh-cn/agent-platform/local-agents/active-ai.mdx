主动 AI 建议基于您的终端错误、输入和输出主动建议修复和下一步操作。功能包括激活 Agent 模式的提示建议、从您的 shell 历史预测的下一个命令，以及自动为命令行错误呈现修复的建议代码差异。

:::note
主动 AI 功能可以在**设置** > **Agent** > **Warp Agent** 中使用主动 AI 切换禁用。
:::

### 提示建议

提示建议是上下文的、AI 驱动的建议，可激活 Agent 模式。这些横幅将在特定场景下提供询问 Agent 模式的建议。

### 下一个命令

下一个命令使用 AI 基于您的活动终端会话和命令历史建议要运行的下一个命令。

### 建议代码差异

建议代码差异自动为在 Warp 中遇到的命令行错误呈现潜在修复。这些最常见的是编译器错误，但也可能包括 Warp 可以自信预测直接解决方案的其他情况。
