**Agent 会话共享**扩展了 Warp 的常规[会话共享](/knowledge-and-collaboration/session-sharing/)，包括对 Agent 活动的完全可见性和控制。共享任何 Agent 会话——Oz 或第三方——以便协作者可以从 Warp 应用、Web 浏览器或移动设备观看进度、审查输出和引导 Agent。

## 关键能力

* **完整的 Agent 可见性** - 查看者实时看到 Agent 提示、响应、思考状态、工具使用、规划步骤和积分消耗
* **跨设备访问** - 从 Warp 应用、任何 Web 浏览器或移动设备打开共享会话
* **协作编辑** - 授予编辑访问权限，以便协作者可以发送自己的 Agent 查询、执行命令和开始新对话
* **多查看者支持** - 多个参与者可以同时观察和交互同一会话
* **远程控制** - 将第三方 Agent 会话发布到云端以进行持久、异步监控和引导

## 使用共享会话审查 Agent 工作

共享 Agent 会话链接时，协作者可以检查工作的详细程度与您在 Agent 运行时看到的相同。

## 如何工作

共享 Agent 会话时，Warp 将其发布到云端并生成可共享链接。会话保持同步——任何新的 Agent 输出或终端活动对所有查看者实时显示。

## 发布会话

1. 在 Warp 中启动或打开 Agent 会话
2. 从命令面板、窗格标题、右键上下文菜单或 `/remote-control` 芯片打开共享操作
3. 选择起点（完整回滚、无回滚或特定块）
4. 确认共享。Warp 将会话上传到云端并生成可共享链接
5. 复制链接并与团队成员共享
