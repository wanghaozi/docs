Warp 的本地 Agent 是直接嵌入终端的交互式 Agent，帮助您使用自然语言编写代码、调试问题、运行命令和自动化开发任务。Agent 以您的代码库、Warp Drive 和连接工具的完整上下文运行，同时您控制每一步操作。

## Warp 中的 AI

Warp 包含智能 Agent，旨在帮助您构建、测试、部署和调试，同时保持您的控制。Warp 中的交互式 Agent 对话可以查找命令、执行任务、修复 Bug 和适应您的工作流。

## 您可以用 Agent 做什么

* [与 Agent 交互](/agent-platform/local-agents/interacting-with-agents/) - 管理与会话绑定的 AI 对话、附加上下文、继续先前线程或开始新线程
* [Agent 上下文](/agent-platform/local-agents/agent-context/) - 附加图像、URL、文件、代码块和选择作为提示的上下文
* [模型选择](/agent-platform/inference/model-choice/) - 从精选顶级模型中选择偏好的 LLM，或让 Warp 选择最优模型
* [完整终端使用](/agent-platform/capabilities/full-terminal-use/) - 让 Agent 驱动交互式终端应用，查看实时输出和运行命令
* [交互式代码审查](/agent-platform/local-agents/interactive-code-review/) - 审查 Agent 生成的差异、留下内联评论
* [任务列表](/agent-platform/capabilities/task-lists/) - 使用自动更新进度的任务列表跟踪复杂工作流程
* [Web 搜索](/agent-platform/capabilities/web-search/) - 允许 Agent 搜索 Web 以获取最新信息
* [第三方 CLI Agent](/agent-platform/cli-agents/overview/) - 使用 Warp 内置的 Agent 工具带运行第三方 CLI Agent
* [主动 AI 建议](/agent-platform/local-agents/active-ai/) - 基于错误和输出获取主动修复建议
* [语音](/agent-platform/local-agents/interacting-with-agents/voice/) - 使用语音命令与 Warp 的 Agent 对话
