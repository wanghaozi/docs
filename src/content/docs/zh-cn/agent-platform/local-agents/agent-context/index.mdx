---
title: Agent 上下文概述
description: >-
  如何在提示中直接将各种形式的多模态上下文附加到 Warp 的 Agent。
---

在 Warp 中，您可以将不同类型的输入直接传递给 Agent 以指导其行为和提高响应质量。这些输入称为 **Agent 上下文**：您在会话期间手动提供的临时信息片段。

**您可以通过多种方式附加上下文：**

* [代码块作为上下文](/agent-platform/local-agents/agent-context/blocks-as-context/) - 共享终端输出以帮助 Agent 理解错误、日志或先前命令。
* [图像作为上下文](/agent-platform/local-agents/agent-context/images-as-context/) - 包含截图、图表或其他视觉内容以提供额外清晰度。
* [URL 作为上下文](/agent-platform/local-agents/agent-context/urls-as-context/) - 附加公共网页以便 Agent 提取和引用其内容。
* [选择作为上下文](/agent-platform/local-agents/agent-context/selection-as-context/) - 从编辑器或审查面板附加代码片段以用精确上下文丰富您的提示。
* [使用 @ 添加上下文](/agent-platform/local-agents/agent-context/using-to-add-context/) - 直接在提示中引用文件、文件夹、代码符号或 Warp Drive 对象。

这与规则、Warp Drive 和 MCP 等其他持续或自动上下文来源不同。
