---
title: 选择作为上下文
description: >-
  直接从 Warp 的编辑器或代码审查面板附加文本或差异作为 Agent 提示的上下文。
---

直接从 Warp 的代码编辑器或代码审查面板附加文本选择或差异块作为 Agent 提示的上下文。选择代码，按下键盘快捷键，Warp 自动将文件路径、行号和内容插入到提示中。

### 从 Warp 的原生代码编辑器附加选择

1. 在编辑器中选择文本。选择区域右下角会出现工具提示。
2. 通过点击工具提示或使用键盘快捷键 `Cmd + L`（macOS）或 `CTRL + SHIFT + L`（Windows/Linux）**添加为上下文**。
3. Warp 自动将相对文件路径和上下文以及差异的行号添加为格式化的字符串到提示中。

### 从 Warp 的代码审查面板附加选择

1. 悬停在任意**差异块**上，显示将其附加为上下文的选项。
2. 附加差异将自动将相关文件路径和更改行插入到提示中。

### 向第三方 Agent 会话附加代码

当第三方 Agent 在 Warp 标签中运行时，在 Warp 的代码编辑器或代码审查面板中选择文本，并使用 `Cmd + L`（macOS）或 `CTRL + SHIFT + L`（Windows/Linux）将其附加为上下文到该 Agent 的会话。
