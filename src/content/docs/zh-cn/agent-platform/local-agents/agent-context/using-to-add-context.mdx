在 Agent 提示中使用 @ 符号引用文件、文件夹、代码符号、Warp Drive 对象和其他会话的代码块作为上下文。@ 菜单从项目根目录搜索整个 Git 仓库，无需代码库索引即可立即工作。

## @ 上下文菜单如何工作

在 **Git 仓库**内时，输入 @ 打开一个上下文菜单，允许您搜索和选择要包含的文件或目录。

:::note
使用 @ 附加上下文在**自然语言模式**（与 Agent 交互时）和**经典终端命令**中引用文件路径时均有效。
:::

### 引用代码符号

@ 菜单也可用于模糊搜索代码库中的代码符号，包括函数、类、接口等。指向特定符号可让 Agent 获得精确上下文以进行有针对性的编辑或解释。

### 引用 Warp Drive 对象

使用 **@** 引用工作流、笔记本和规则。选择这些对象之一后，Warp 会将引用令牌插入到提示中。对象内容自动作为上下文传递给 Agent。

### 引用其他会话的代码块

您不限于当前终端会话。使用 @，您还可以从更早的会话中引入输出块。
