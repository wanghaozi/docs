---
title: URL 作为上下文
description: >-
  将公共 URL 附加到提示中，以便 Agent 可以引用该页面的内容。
---

将公共 URL 附加到任何 Agent 提示以提供页面内容作为上下文。Warp 抓取页面并将提取的文本直接呈现给模型，使 Agent 能够访问文档、参考或任何可公开访问的 Web 内容。

## 通过 URL 引用网站

* 仅支持可公开访问的页面。
* 完整页面添加到模型的上下文中，对于长文档可能会增加积分使用。
* 仅处理您提供的特定 URL。Agent 不会探索网站、跟踪链接或在该页面之外爬取。

:::note
**重要**：URL 附件与 Web 搜索不同。如果您需要 Agent 查找内容、收集实时信息或拉取多个源，请改用 [Web 搜索](/agent-platform/capabilities/web-search/)。
:::
