将截图、图表或其他图像直接附加到 Agent 提示中，以便 Agent 在生成响应时可以使用视觉上下文。Warp 支持拖放、复制粘贴和文件上传，每次请求最多 5 张图像，适用于所有受支持的模型。

## 附加图像作为上下文

* 使用工具栏上的图像上传按钮
* 直接复制粘贴图像
* 拖放图像

:::note
Warp 接受以下图像格式：`.jpg`、`.jpeg`、`.png`、`.gif` 和 `.webp`。
:::

每次请求最多可附加 **5 张图像**，单次对话最多 **20 张图像**。每张图像发送给模型提供商后立即丢弃——不会存储在 Warp 的服务器上。

:::caution
**云 Agent 对话目前不支持图像附件。** 图像附件仅在本地 Agent 对话中可用。如果您需要向云 Agent 提供视觉上下文，请描述图像内容或引用 agent 的[环境](/agent-platform/cloud-agents/environments/)中的图像文件路径。
:::
