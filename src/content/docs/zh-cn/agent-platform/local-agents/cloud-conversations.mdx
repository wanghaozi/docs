Warp 可以将您的 Agent 对话同步到云端，使它们跨设备可访问、可与团队成员共享，并在登出后持久存在。这使您可以在任何机器上从上次中断的地方继续、与协作者共享上下文，以及访问过去的云 Agent 对话。

## 关键能力

* **跨设备持久性** - 登出并重新登录或切换到不同机器时对话仍然可用。
* **访问过去的云 Agent 对话** - 查看和恢复已完成的云 Agent 对话。
* **带访问控制的链接共享** - 与特定团队成员或团队共享对话，具有可配置的权限。
* **Web 查看** - 在浏览器中查看共享对话，无需安装 Warp。
* **本地继续** - 恢复任何云对话并在您的机器上本地继续。

## 启用云对话

1. 打开**设置** > **隐私**
2. 启用**在云端存储 AI 对话**

## 如何工作

### 对话同步
启用后，Warp 在每次 Agent 交互后自动同步对话数据。这在后台进行，不影响工作流程。

### 继续 vs. 分叉
恢复云对话时：您自己的对话可直接继续；来自他人的共享对话会创建分叉。
