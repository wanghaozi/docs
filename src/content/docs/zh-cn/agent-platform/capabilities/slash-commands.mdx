title: 斜杠命令
description: >-
  在 Agent 模式或自动检测模式下使用斜杠命令快速运行内置操作或已保存的提示，无需离开输入字段。
---

斜杠命令是您可以通过在 Agent 模式或自动检测模式下键入 `/` 来调用的快速操作和已保存提示。它们提供对内置操作的即时访问，如开始对话、创建环境、切换模型、打开静态流以及运行 Warp Drive 中的已保存提示。

<figure>
![斜杠命令菜单](../../../../../assets/agent-platform/slash-commands-menu.png)
<figcaption>斜杠命令菜单。</figcaption>
</figure>

当您键入时，菜单会实时过滤结果，使查找和运行所需命令或提示变得容易。

#### 通过斜杠命令使用 Agent 提示

除了静态命令外，菜单还显示保存在您的 [Warp Drive](/knowledge-and-collaboration/warp-drive/) 中的 [Agent 提示](/knowledge-and-collaboration/warp-drive/prompts/)。

* 这些提示可以是您创建的自定义提示，也可以是他人与您共享的提示。
* 当您在 `/` 后键入时，提示会动态过滤，因此您可以快速运行它们而无需离开输入字段。

![带有过滤后的 Agent 提示的斜杠命令菜单](../../../../../assets/agent-platform/slash-commands-prompts.png)

### 提示

* **上下文感知：** 许多斜杠命令使用您当前的工作目录或文件选择作为上下文。
* **快速访问：** 在 Agent 模式或自动检测模式下从任何位置使用 `/`，以避免在菜单中导航。
