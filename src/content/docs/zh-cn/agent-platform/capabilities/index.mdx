Agent 能力是定义 Warp 的 agent 如何运行的核心构建块，包括 agent 可以访问的上下文来源、指导其行为的规则、它们可以使用的工具以及它们运行的模型。配置这些能力以匹配您的工作流程和偏好。

## 本节中的能力

* [斜杠命令](/agent-platform/capabilities/slash-commands/) - 在 Agent 模式下通过输入 `/` 可访问的快速操作和已保存提示。
* [技能](/agent-platform/capabilities/skills/) - 可重用、有作用域的指令，教导 agent 如何在您的代码库中执行特定任务。
* [规划](/agent-platform/capabilities/planning/) - 将 agent 请求转化为有序、可编辑的计划，逐步执行并具有完全可见性。
* [任务列表](/agent-platform/capabilities/task-lists/) - 使用自动更新进度的任务列表跟踪复杂工作流。
* [规则](/agent-platform/capabilities/rules/) - 定义塑造 agent 行为和响应的全局和项目级指导方针。
* [完整终端使用](/agent-platform/capabilities/full-terminal-use/) - 让 agent 驱动交互式终端应用，查看实时输出和运行命令。
* [计算机使用](/agent-platform/capabilities/computer-use/) - 让 agent 通过截屏、点击、输入和控制 GUI 与桌面环境交互。
* [MCP](/agent-platform/capabilities/mcp/) - 通过模型上下文协议将外部数据源和工具连接到 Warp 的 agent。
* [代码库上下文](/agent-platform/capabilities/codebase-context/) - 通过对 Git 追踪文件的语义索引，让 agent 理解您的代码库。
* [Agent 配置文件与权限](/agent-platform/capabilities/agent-profiles-permissions/) - 控制 agent 运行命令和应用更改的权限和自主权。
* [Web 搜索](/agent-platform/capabilities/web-search/) - 允许 agent 搜索 Web 以获取最新信息。
