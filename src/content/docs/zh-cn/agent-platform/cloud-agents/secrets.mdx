云 Agent 通常需要与外部系统如 API、数据库、云提供商或内部工具交互。为此，Warp 提供 Warp 管理的 **Agent 密钥**，一种安全存储、限定范围和向云 Agent 运行注入凭据的方式，而不向用户或日志暴露密钥值。

Warp 管理的密钥设计用于跨[云 Agent](/agent-platform/cloud-agents/overview/)和[集成](/agent-platform/cloud-agents/integrations/)触发器（CLI、Slack、Linear 和计划），支持团队范围和个人凭据，并为工程和安全团队提供对 Agent 可以访问什么内容的可见性。

### 密钥作用域

每个密钥都有一个决定谁可以使用它的作用域。

#### 团队密钥

团队密钥跨整个团队共享，对代表团队运行的所有云 Agent 可用。

**关键特征：**

* 始终注入云 Agent 运行，无论 Agent 如何触发（CLI、Slack、Linear 或计划运行）
* 对有或没有特定用户上下文的运行的 Agent 可用
* 适用于共享的基础设施凭据、服务账户和只读 API 密钥

#### 个人密钥

个人密钥属于**个人用户**。

* 仅对由该用户触发的云 Agent 可用
* 对团队成员或无人触发器不可访问
* 适用于个人 API 密钥或绑定到个人账户的凭据

---

## 使用 Oz CLI 管理 Agent 密钥

```bash
# 交互式创建团队密钥
oz secret create --team METABASE_API_KEY

# 从文件创建个人密钥
oz secret create --personal --value-file api_key.txt METABASE_API_KEY

# 列出密钥
oz secret list

# 更新密钥值
oz secret update --team --value METABASE_API_KEY

# 删除密钥
oz secret delete --team METABASE_API_KEY
```
