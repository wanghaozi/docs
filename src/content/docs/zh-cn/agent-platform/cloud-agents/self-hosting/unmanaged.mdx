使用非托管架构，**您编排 Agent 运行**，通过从现有 CI 流水线、Kubernetes Pod、VM 或开发机直接调用 `oz agent run`。Agent 在命令执行的任何主机上运行；Warp 为您跟踪会话，但不启动或停止 Agent。

## 何时使用非托管

* **CI/CD 流水线** — 作为构建或部署工作流的一部分运行 Agent
* **Kubernetes Pod** — 在 Pod 内运行 Agent，访问集群的网络和服务
* **开发机和 VM** — 在预先配置的开发环境中运行 Agent
* **现有编排器** — 将 `oz agent run` 放入任何调度工作的系统

## 非托管快速入门

### 前提条件
* 机器上安装 Oz CLI
* Warp API 密钥

### 1. 认证

```bash
export WARP_API_KEY="your_team_api_key"
```

### 2. 运行 Agent

```bash
oz agent run --prompt "Refactor the authentication module" --share team
```

### 3. 控制共享

使用 `--share` 控制谁可以附加到会话：
* `--share` — 与自己共享
* `--share team` — 所有团队成员只读
* `--share team:edit` — 所有团队成员读写

## 示例：GitHub Actions

```yaml
- name: Run agent
  uses: warpdotdev/oz-agent-action@v1
  with:
    prompt: "Review the code changes on this branch"
    warp_api_key: ${{ secrets.WARP_API_KEY }}
```

## 示例：Kubernetes

```yaml
apiVersion: batch/v1
kind: Job
metadata:
  name: oz-agent-task
spec:
  template:
    spec:
      containers:
      - name: oz-agent
        image: warpdotdev/warp-agent:latest
        command: ["agent", "run", "--prompt", "Run the test suite"]
        env:
        - name: WARP_API_KEY
          valueFrom:
            secretKeyRef:
              name: warp-credentials
              key: api-key
      restartPolicy: Never
```
