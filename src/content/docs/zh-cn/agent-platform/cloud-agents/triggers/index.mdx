---
title: 触发器概述
description: >-
  配置触发器以根据计划或事件自动运行云 Agent。
---

触发器允许您无需手动干预即可自动运行云 Agent。您可以设置 Agent 按计划运行、响应 Webhook 或通过其他自动化模式运行。

要设置您的第一个重复 Agent，请遵循[计划 Agent 快速入门](/agent-platform/cloud-agents/triggers/scheduled-agents-quickstart/)。

## 可用触发器类型

* **[计划 Agent](/agent-platform/cloud-agents/triggers/scheduled-agents/)** - 使用 cron 表达式按重复计划运行 Agent。
* **[CLI](/reference/cli/)** - 使用 Oz CLI 直接从终端触发云 Agent。
* **[API & SDK](/reference/api-and-sdk/)** - 通过 Warp API 或 SDK 以编程方式触发 Agent。
* **[集成](/agent-platform/cloud-agents/integrations/)** - 从 Slack、Linear 或 GitHub Actions 等外部服务触发 Agent。
