云 Agent 会话共享让您打开、检查并继续与在远程虚拟机上运行的 Agent 任务交互。无论云 Agent 是从[集成](/agent-platform/cloud-agents/integrations/)如 Slack、Linear、GitHub Actions 还是 [Oz CLI](/reference/cli/) 触发的，您都可以查看其完整会话、实时跟进、提出后续问题，甚至将工作"分叉"到本地 Warp 环境。

## 启用功能

* 查看 agent 在虚拟环境中执行的每个命令
* 直接在 Warp 或 Web 查看器中检查上下文、日志和输出
* 审查导致结果的提示、计划、任务列表和决策
* 任务完成后提问或给出额外指令
* 使用分叉到本地将会话带到本地 Warp 会话

## 如何工作

1. **打开远程云 Agent 运行** - 从 Slack 点击 **View Agent**，从 Linear 点击 **Warp** 按钮
2. **像自己的会话一样检查** - 滚动云 Agent 的操作，查看记录
3. **继续与远程 Agent 聊天** - 即使云 Agent 已完成任务，仍可追问
4. **处理不活动或关闭的会话** - 点击 **Fork to local**
5. **将会话分叉到本地 Warp** - 将会话带到本地机器
