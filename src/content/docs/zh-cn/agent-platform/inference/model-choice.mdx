Warp 让您从精选的 LLM 集合中为您的 Agent 选择模型，或让 Warp 为每个任务自动选择最佳模型。来自 OpenAI、Anthropic、Google 和开源提供商的模型均可用，具有可配置的推理级别和按配置文件设置的默认值。

## 可用模型

### Auto 模型

| 模型 | `model_id` | 描述 |
| --- | --- | --- |
| Auto（响应式） | `auto` | 选择最高质量、最快的可用模型 |
| Auto（成本高效） | `auto-efficient` | 优化更低积分消耗，同时保持强输出质量 |
| Auto（天才） | `auto-genius` | 适应任务复杂性，在值得时选择 Warp 最强大的模型 |
| Auto（开源权重） | `auto-open` | 使用 Warp 中最佳开源模型之间路由 |

### OpenAI - GPT-5.5、GPT-5.4、GPT-5.3 Codex、GPT-5.2 Codex、GPT-5.2

### Anthropic - Claude Opus 4.7、Claude Opus 4.6、Claude Sonnet 4.6、Claude Opus 4.5、Claude Sonnet 4.5、Claude Haiku 4.5

### Google - Gemini 3.1 Pro

### 托管模型（通过 Fireworks AI）- GLM 5.1、Kimi K2.5、Kimi K2.6、Minimax 2.7、Qwen 3.6 Plus

### 如何更改模型

点击显示的模型名称以打开下拉菜单。您的选择自动持久化用于未来的提示。

### 模型回退

如果您的选定模型不可用，Warp 自动使用回退模型继续对话。
