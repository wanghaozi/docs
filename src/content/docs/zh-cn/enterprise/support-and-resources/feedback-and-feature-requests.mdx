Warp Enterprise 客户可以通过专属支持渠道报告问题、请求功能和获得帮助。本页说明如何联系正确的团队以及提供快速解决问题所需的信息。

## 企业支持渠道

企业客户通过专属渠道获得**优先支持**：

* **专属 Slack 或 Teams 频道** - 你的主要支持渠道。与 Warp 工程师共享的私有频道，用于实时帮助、错误报告和功能讨论。
* **客户经理** - 你的直接联系人，用于升级问题、战略性功能请求和企业特定问题。

:::note
为获得最快的响应速度，请使用你的专属 Slack 或 Teams 频道。Warp 工程师在工作时间监控这些频道。
:::

## 报告错误

报告错误时，请包含以下信息以帮助 Warp 团队快速调查：

1. **描述** - 发生了什么以及你期望发生什么。
2. **复现步骤** - 如何触发该问题。
3. **对话 ID**（针对代理问题） - 右键点击相关的代理对话块，选择 **Copy conversation ID**，并将其包含在你的报告中。当代理对话产生错误时，也会出现内联的复制对话 ID 选项。更多详情请参见[获取对话 ID](/support-and-community/troubleshooting-and-support/sending-us-feedback/#gathering-ai-conversation-id)。
4. **日志**（如相关） - 请参见下方的[获取日志](#gathering-logs)。
5. **环境详情** - 操作系统、Warp 版本以及任何相关配置。

:::note
大多数企业团队已禁用用户生成内容（UGC）收集，这限制了从对话 ID 获取的诊断信息。对于企业错误报告，日志和详细的复现步骤尤其重要。
:::

### 获取日志

Warp 的日志不包含控制台输入或输出。各平台的日志文件位置：

* **macOS** - `~/Library/Logs/warp.log*`
* **Windows** - `%LOCALAPPDATA%\warp\Warp\data\logs\warp.log*`
* **Linux** - `~/.local/state/warp-terminal/warp.log*`

你也可以直接在应用中访问日志：打开**命令面板**（macOS 使用 `⌘P` / Windows 和 Linux 使用 `Ctrl+Shift+P`），搜索 **View Warp Logs**。

关于详细的日志收集说明（包括如何压缩日志和捕获崩溃报告），请参见[发送反馈与日志](/support-and-community/troubleshooting-and-support/sending-us-feedback/)。

## 请求功能

要请求新功能或改进：

* **企业客户** - 通过你的专属 Slack/Teams 频道或与你的客户经理分享功能请求。这确保你的请求被产品团队跟踪和优先处理。
* **公开功能请求** - 在 [GitHub Issues](https://github.com/warpdotdev/warp/issues/new/choose) 上提交问题，以获取可见性和社区讨论。

## 专项联系方式

对于安全或隐私相关咨询，请直接联系相应团队：

* **安全问题** - [security@warp.dev](mailto:security@warp.dev)
* **隐私问题** - [privacy@warp.dev](mailto:privacy@warp.dev)

对于所有其他咨询——包括账单、技术问题和功能请求——请联系你的客户经理或专属的 Slack/Teams 频道。
