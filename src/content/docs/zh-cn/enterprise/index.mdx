Warp Enterprise 专为希望在保持安全、合规和管理控制的同时，利用代理加速软件开发的组织而构建。它将 Warp 的**代理驱动开发环境**带到你的整个工程组织，并提供 IT 和安全团队所需的治理功能。

Warp 有两个核心产品：

* **Warp 终端** - 一个专为代理驱动开发设计的现代化终端，开发者可以在此运行命令、与代理协作以及从命令行编排自主工作。
* **Oz** - Warp 的可编程代理，用于大规模运行和协调代理。Oz 为 Warp 中的所有代理提供动力——无论是在本地运行还是在云端运行——并提供可扩展代理工作流所需的编排、跟踪和控制平面。

## Warp Enterprise 的目标用户

Warp Enterprise 服务三类主要用户：

* **IT 管理员和平台团队** - 通过 SSO、集中化管理和使用可见性，在组织中部署和管理 Warp
* **工程经理** - 为团队提供强大的代理开发工具，同时通过共享的团队资源执行编码标准和最佳实践
* **专业开发者** - 借助先进的代理、团队知识共享和协作工作流，加速整个 SDLC 的工作，同时让你保持控制

## 关键能力

### 企业管理
* **单点登录（SSO）** - 通过你现有的身份提供商（Okta、Microsoft Entra ID、Google Workspace 等）进行认证
* **集中式管理面板** - 从一个位置管理团队设置、用户权限和功能控制
* **用户角色与权限** - 通过团队所有者、团队管理员和成员角色控制访问
* **使用可见性** - 监控团队在组织范围内的采用率和代理使用情况

### 安全与合规
* **SOC 2 Type II 认证** - 满足企业安全与合规要求
* **零数据保留（ZDR）** - 签约的 LLM 提供商不保留、存储或使用客户数据进行训练
* **开源客户端** - Warp 的客户端代码以 [AGPL v3](https://github.com/warpdotdev/warp/blob/master/LICENSE-AGPL) 协议发布在 [`warpdotdev/warp`](https://github.com/warpdotdev/warp) 上，供安全审查和审计
* **自带 LLM（BYOLLM）** - 通过你自己的云基础设施（AWS Bedrock）路由推理
* **灵活部署** - 选择 Warp 托管或混合部署模式
* **遥测控制** - 在团队级别配置收集哪些数据

### 团队协作
* **Warp Drive 团队工作空间** - 在团队中共享工作流、笔记本、提示、计划、规则和环境变量
* **代码库上下文** - 团队级代码索引帮助代理理解你的仓库并生成准确的、上下文感知的响应
* **MCP 集成** - 连接到团队的工具（Linear、Sentry、Figma、GitHub 等），实现上下文感知的代理响应
* **会话共享** - 通过可共享链接协作处理终端会话和对话

### 代理能力
* **先进代理** - 支持多种模型的代理，具有完整的终端访问、代码编辑和自主任务执行能力
* **云代理** - 在云端运行代理，实现无限并行化、后台自动化和长时间运行的工作流。适用于 PR 审查、定时任务和跨多个仓库的分布式工作
* **集成控制平面** - 从统一界面启动、编排和管理本地、云端和自主代理。从 Oz 仪表板跟踪团队中所有的代理活动
* **代理配置文件** - 自定义代理行为、模型、自主级别和权限
* **规则与护栏** - 通过团队范围或项目特定的规则，执行编码标准、技术栈偏好和安全实践
* **多代理支持** - 支持所有主要模型和 CLI 编码代理（Oz、Claude Code、Codex、Copilot）

## 企业为何选择 Warp

组织采用 Warp Enterprise 是为了：

* **加速开发速度** - 代理自动化 SDLC 中的繁琐任务，从环境设置到事件响应，让开发者专注于重要的事
* **保持安全与控制** - 在你的基础设施上部署，通过你的云账户路由推理，并通过完全的可见性和护栏让开发者保持控制
* **扩展最佳实践** - 通过 Warp Drive 共享团队知识、编码标准和操作运行手册，放大跨团队的生产力提升
* **减少上下文切换** - 通过终端优先的环境让开发者保持心流，将代理、代码编辑和工具集成整合在一个地方
* **内置脚手架** - 无需构建自定义基础设施即可大规模部署代理——Warp 提供开箱即用的编排、跟踪和协作
